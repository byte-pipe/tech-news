# Build from anywhere with Cursor for iOS

## Launch and track agents from anywhere
- Open the iOS app, select a repository, and start an agent just like on desktop.  
- Choose any frontier model, use voice input, and employ slash commands to steer the agent.  
- For agents on your computer, use Remote Control from the phone; enable a setting to keep the machine awake while you’re away.

## New ways of working from your phone
- **Handling incidents while on call** – start an agent to investigate and propose a fix; a PR is ready when you return to your desk.  
- **Resolving customer issues** – launch an agent to reproduce a bug, inspect code, and begin a fix while you’re away.  
- **Acting on feedback from other mobile apps** – capture screenshots, annotate, and send them as visual context to an agent for rapid design or UI changes.

## Stay in the loop
- Agents send Live Activities to the lock screen and push notifications when they finish, need input, or are ready for review.  
- Cloud agents generate demos, screenshots, and logs; you can review artifacts, inspect diffs, add instructions, or merge PRs directly from the app.

## Handoff between local and cloud
- Cloud agents run in isolated VMs with full development environments, allowing longer, asynchronous runs toward merge‑ready PRs.  
- Send a local plan to a cloud agent or move active agents to the cloud; you can later bring the cloud session back to your computer for local testing before merging.

## What’s next
- Aim to make cloud‑based agent experience indistinguishable from local execution, with seamless Remote Control and handoffs.  
- Planned features include repo‑less chats for tasks without codebase context.  
- Teams are already using agents to query Datadog logs, summarize Slack activity, etc.
