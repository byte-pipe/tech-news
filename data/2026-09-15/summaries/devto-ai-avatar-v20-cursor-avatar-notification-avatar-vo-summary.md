# AI Avatar v20, Cursor Avatar, Notification Avatar (Voxel Avatar)🧊

## Intro
- AI Avatar is a free app that animates your VRoid (VRM) avatar in VS Code sidebar or Chrome side panel.
- It reacts to Claude Code, GitHub Copilot, ChatGPT, or Claude without needing AI for animations.
- The post focuses on four topics: Voxel Avatar, Kaleidoscope, Cursor Avatar, Notification Avatar.

## Voxel Avatar
- Added an idle‑game mode inspired by a collaborator, Maximum Blue.
- The mode features a Minecraft‑style voxel flower garden that grows automatically via Claude Code or manually by clicking.
- Users can level land, plant flowers, add butterflies, experience rain and rainbows.
- The main challenge was creating 3D flower models in Three.js; the AI initially produced a cylinder‑sphere shape, requiring detailed step‑by‑step guidance.
