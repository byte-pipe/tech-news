# GitHub - CopilotKit/CopilotKit: The Frontend Stack for Agents & Generative UI. React + Angular. Makers of the AG-UI Protocol · GitHub

**CopilotKit Overview**

CopilotKit is a best-in-class system design kit (SDK) for building full-stack agentic applications, generative UI, and chat applications. It enables developers to build flexible, responsive, and human-in-the-loop experiences with ease.

* **Architecture**: CopilotKit consists of four key components:
 + React-based chat interface
 + Backend tool rendering
 + Generative UI (AI-generated UI components)
 + Shared state synchronization
 +

**Key Features**

* Chat UI: Customizable chat interface that supports message streaming, tool calls, and agent responses.
* Backend Tool Rendering: Enables agents to call backend tools that return UI components directly in the client.
* Generative UI: Allowing agents to generate and update UI components dynamically at runtime based on user intent and agent state.
* Shared State: Synchronized state layer for both agents and UI components to read from and write to in real-time.

**Benefits**

* Easy development experience: CopilotKit's React-based chat interface, backend tool rendering, generative UI, and shared state synchronization simplify the development process.
* Flexibility: Designers can use these features to create custom applications with a wide range of possibilities.

**Getting Started**

To use CopilotKit, run `npx copilotkit@latest create -f framework` for a new project or `npx copilotkit@latest init <project-name>` for an existing one.
