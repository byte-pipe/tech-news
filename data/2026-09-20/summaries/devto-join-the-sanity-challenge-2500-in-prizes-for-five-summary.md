# Join the Sanity Challenge: $2,500 in prizes for FIVE winners! - DEV Community

## Sanitizing the Content with Sanity: $2,500 in Prizes

The Sanity Challenge is an exciting initiative that encourages developers to build innovative applications on the AI Content Operating System (Sanity). In this challenge, participants are presented with different prompts to create an AI agent or vibe-code an app with Sanity as the backend. The grand prize for the winner is $2,500.

## What is Sanity?
Sanity is a powerful AI Content Operating System that allows developers to build anything they can imagine with structured content. This content is stored in JSON documents with defined schemas, enabling developers to use it to create applications that are both intelligent and accessible to users.

## Prompts for the Challenge

Two main prompts are available to participants:

### Path One: Shipping an AI Agent

Create an agent that queries real content using a Sanity Context MCP endpoint with a Knowledge Base. The agent can be used to build applications that require accurate and reliable answers. Examples of applications that can be built include a board game, a better interface to open-source documentation, and a euorack planner.

### Path Two: Vibecoding an Application

Develop an application with Sanity behind it. This application can handle any task possible with structured content, including building tools, apps, or workflows. Participants are encouraged to venture beyond the typical front-end applications and create something truly new and innovative.

## Submission Templates

The submission templates for Path One and Path Two are as follows:

* Path One: A strong submission is one that demonstrates how the content has been structured, ensuring it can only work correctly due to the structured format. It's recommended that keyword searches were able to provide the desired answer.
* Path Two: A submission that has successfully built an application on top of Sanity features and uses it in a creative way will be considered more high-quality. It's essential to go beyond the typical front-end build with an AI-native IDE, and some unconventional features are even preferred.
