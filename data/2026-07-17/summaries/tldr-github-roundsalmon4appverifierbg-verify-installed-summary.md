# GitHub - RoundSalmon4/AppVerifierBG: Verify installed apps against shared signature hashes, the internal database, or a user-created database. · GitHu...

Here is a concise and informative summary of the article:

**Overview**

AppVerifier BG fork from soupslurpr/AppVerifier includes additional features for verifying installed apps against shared signature hashes, internal database, or user-created databases.

**Key Points:**

* Pasted hashes are checked for valid SHA-256 format
* Verification results include expected vs. found hash comparison with collapsible toggle
* Expected vs. found hash comparison allows for flexible reporting of matches and mismatches
* Apps signed with debug certificates are flagged as insecure

**Features:**

* Internal database matches provide visual indicators (status icons)
* User-created databases allow filtering by data type
* Shared text verification includes filter functionality
* Long-press on apps with user database entries or clipboard checks for individual removal

**Navigation and Management:**

* Easily view all installed user apps through folder listing
* Sort apps by attributes (name, database status, debug builds, clipboard verified, shared text), or add custom sorting options
* Search by name or package name to filter app list
* Bulk-add verified matches from shared texts with multiple entries
