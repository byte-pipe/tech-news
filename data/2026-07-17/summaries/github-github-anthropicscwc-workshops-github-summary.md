**Anthropic's CWC Workshops Documentation**
=====================================

### Overview

CWC Workshops is an initiative by Anthropic aimed at developing managed, automated systems for complex tasks. These workshops provide a structured approach to tackling specific problems using the Claude Code framework and associated technologies.

### Notable Workshops

*   **Rightmodel**: This workshop explores selecting the right neural network model using the Claude code Skill and evaluates it against other models and inference parameters (effort) to find the best-per-dollar and quality-second configuration.
*   **Agent Decomposition**: This phase of Rightmodel involves decomposing a 400-line-prompt inventory agent into skills, code execution, and callable agents on Claude managed agents. Evaluations are conducted to verify each step.
*   **Ship Your First Managed Agent**: This workshop aims at deploying the first managed agent, involving a Streamlit incident dashboard with an offline SRE agent chat panel. It promotes implementing simple functions in `agent.py` to facilitate deployment.

### Key Principles

1.  Use Claude Code skills for selecting meaningful neural network models.
2.  Decompose complex tasks into smaller components using skills, code execution, and callable agents on managed resources.
3.  Monitor, evaluate, and optimize these systems throughout the workflow process.
