# StreetComplete Summary

## Overview
- OpenStreetMap surveyor app designed to help improve the map.
- Finds missing map data near the user and presents them as quests.

## How It Works
- Displays quests on a map for nearby missing information.
- Users visit the location on‑site and answer a simple question.
- The entered information is added directly to OpenStreetMap under the user’s name, eliminating the need for another editor.
