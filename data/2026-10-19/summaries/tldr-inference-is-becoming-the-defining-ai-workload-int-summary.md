# Inference is becoming the defining AI workload: Intel GPU D-series launched with the world’s largest 480 GB capacity and air‑cooled 350 W design

## Key specifications
- 480 GB of LPDDR5X memory – the highest capacity for a data‑center GPU, surpassing Nvidia’s Blackwell Ultra B300 (288 GB HBM3e)  
- 1.3 PFLOPS FP8 compute performance, a format that speeds AI tasks while reducing memory use  
- 1.5 TB/s memory bandwidth for rapid data movement between memory and processor  
- 350 W power envelope, standard PCIe form factor, and air‑cooling to fit existing racks without special cooling infrastructure  

## Design choices
- Intel selected LPDDR5X (common in laptops) instead of GDDR7 or HBM, emphasizing memory capacity and power efficiency for inference workloads rather than gaming performance  
- The accelerator includes specialized AI compute hardware and is designed to work alongside Intel Xeon CPUs for task coordination and data handling  
- Software compatibility is maintained across Intel’s GPU portfolio, easing integration for developers  

## Target workloads and positioning
- Supports single‑card models up to 300 billion parameters; an eight‑GPU configuration can handle models exceeding one trillion parameters  
- Optimized for long prompts, simultaneous inference requests, enterprise AI services, and robotics that require responsive processing  
- Intel positions the D‑series as a cost‑effective solution for the growing inference‑centric AI market, aiming to make high‑capacity inference practical to deploy and economical to scale  

## Competitive context
- While memory size is a headline metric, overall performance also depends on bandwidth, compute resources, software stack, and specific workload characteristics  
- Intel rates the D‑series at 1.3 PFLOPS FP8 and 1.5 TB/s bandwidth, providing a benchmark for comparison with competing GPUs  

## Availability and pricing
- Intel has not disclosed a retail price or a definitive general‑availability date for the GPU D‑series at the time of writing.
