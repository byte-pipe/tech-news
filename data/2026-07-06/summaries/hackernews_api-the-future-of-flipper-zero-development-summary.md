# The Future of Flipper Zero Development

## TL;DR
- Resources are now allocated to maintain the Flipper Zero firmware.  
- Community requests and contributions will follow new rules: voting in GitHub Discussions, clearer pull‑request guidelines, and mandatory integration testing.

## Kickstarter 2020 – How it began
- Kickstarter launch generated massive community support and intense skepticism.  
- The team faced component shortages, supply‑chain cost spikes, and political turmoil after COVID.  
- Despite accusations and threats, the team carefully planned resources, took risks, and delivered:
  - All Kickstarter promises fulfilled; every backer received a device.  
  - Every advertised feature implemented after years of development.  
  - A robust platform with APIs, SDK, and tools that fostered many community projects.  
  - Worldwide availability achieved through regulatory certifications and customs approvals.

## Stable firmware 1.0
- Flash memory limit (700 KB) led to a dynamic app‑loading system from the microSD card.  
- Firmware 1.0, released in 2024, solidified this architecture, polished UI, and stabilized the API/SDK.  
- The team now focuses on maintaining infrastructure, fixing critical bugs, and developing new devices, while the community drives alternative firmware and feature extensions.

## New approach to community contribution
- Team size remains small; primary focus is on new devices, not real‑time chat support.  
- All official communication will be asynchronous via GitHub Discussions; votes determine priority.  
- Updated contribution guide enforces stricter pull‑request review, especially for AI‑generated low‑level code and UI changes.  
- Public integration‑test cases will be required for every code change, with community help on regression testing.

## Feature requests via GitHub Discussions
- Direct real‑time interaction became impractical after reaching one million users.  
- All feature requests are now submitted and voted on in GitHub Discussions.  
- Only well‑justified, broadly useful requests will be considered; niche or personal ideas are redirected to Discord, Reddit, Twitter, etc.

## Summary
- The team commits resources to ongoing firmware maintenance and weekly review of community input.  
- Communication with developers is now limited to GitHub Discussions, with priority given to the most‑voted feature requests.  
- Clear contribution guidelines and mandatory testing aim to ensure stability while encouraging community involvement.
