# Linus Torvalds says AI‑powered bug hunters have made Linux security mailing list ‘almost entirely unmanageable’

## Main points
- Linus Torvalds warned that the Linux kernel security mailing list is “almost entirely unmanageable” because many researchers use AI tools to discover the same bugs and submit duplicate reports.  
- He noted that most AI‑found bugs are already public, so handling them on a private list creates “pointless churn” and wastes developers’ time.  
- Torvalds urged reporters to read the kernel documentation, submit patches, and add genuine value beyond the AI‑generated finding instead of sending “drive‑by” reports.  
- In his weekly “state of the kernel” post he announced release candidate 4 for Linux 7.1, describing progress as “fairly normal” and mentioning an optional new NTFS driver.  
- His stance contrasts with kernel maintainer Greg Kroah‑Hartman, who recently praised AI as an increasingly useful tool for the open‑source community.  
- Torvalds emphasized that AI tools are helpful only when they improve security work rather than generate unnecessary duplication.
