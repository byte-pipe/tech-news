# free-stockdb 项目概述

## 项目简介
- 本地量化数据引擎，面向 A 股日线、分钟线以及 ETF 分钟、tick 级数据  
- 将数据同步、清洗、复权后组织为可直接批量查询、计算的底层数据集  
- 支持双击更新、双击启动，使用者无需依赖远程接口  

## 核心功能
- **增量同步**：仅处理变化数据，支持 Zstd 压缩传输与断点续传  
- **本地存储**：数据落盘后可离线查询、回测，避免远程 API 限频与 IP 封禁  
- **复权处理**：内置完整复权因子，查询时可实时计算前复权、后复权或不复权  
- **指标计算**：内置 39 种技术指标 + 5 种指数计算，Rust 计算核心比 pandas 快约 3 倍  
- **板块映射**：内置申万一级、二级、三级以及 1200+ 概念板块，支持毫秒级查询

## 使用流程（两分钟上手）
1. 下载 Windows 发行包（Releases）并运行数据更新工具  
2. 数据同步至 `./data` 目录  
3. 启动 `stockdb`（仅 2.2 MB）  
4. 通过 Python SDK、HTTP API、Excel/WPS、HTML 页面或 MCP 直接查询本机数据  

## 数据存储与来源
- 首次同步从 `sync_url.txt` 配置的源获取完整历史数据，后续仅同步增量  
- 数据采用 Zstd 压缩，磁盘占用约为 CSV/MySQL 的 1/3  
- 支持自定义数据源：可切换 sync_url、使用 `file://` 本地快照、或接入其他行情接口  
- 高频行情与复权为默认数据集，低频数据（财报、宏观等）可按需接入同一查询引擎  

## 调用方式
| 方式 | 适用场景 |
|------|----------|
| Python SDK | 回测、研究、策略开发（同步 `get_data()`、异步 `get_data_async()`） |
| HTTP API | 任意语言或系统集成（`http://127.0.0.1:7899/?cmd=get&t=...`） |
| Excel / WPS 宏 | 表格分析、选股、办公自动化 |
| HTML 页面 | 无代码查看、筛选、浏览本地行情 |
| AI MCP | Claude、Cursor、Windsurf 等 AI 工具直接查询、计算本地数据（自实现 MCP 协议，无需额外 SDK） |

- 示例代码位于 `调用方式/` 目录  
- 主要查询函数：`get_data()`（全市场、字段筛选）、`zb.get()`（指标/指数计算）、`bk.get()`（板块映射）  

## 硬件与安全要求
- **磁盘空间**：约 5 GB（仅日线）或约 20 GB（含全量分钟线）  
- **内存**：最低 2 GB，推荐 8 GB+  
- **操作系统**：Windows 7+ / Windows 10+（mac、Linux 版本即将发布）  
- **网络安全**：服务默认监听 `127.0.0.1:7899`，不暴露公网；同步文件在写入前校验 SHA‑256 与大小，建议使用 HTTPS  

## 源码与构建
- C++ 实现位于 `cpp/`，包含本地服务、同步器、客户端示例及 CMake 构建脚本  
- 构建要求：CMake 3.14+、C++17 编译器、libcurl、OpenSSL 开发包  
- Windows 用户可直接使用预编译发行包，无需自行编译
