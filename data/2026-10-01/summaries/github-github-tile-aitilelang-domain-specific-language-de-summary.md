# Tile Language (tile-lang) Documentation
=====================================================

## Overview
-----------

Tile Language is a domain-specific language designed to streamline the development of high-performance GPU/CPU/NPU kernels. It integrates a Pythonic syntax with a compiler infrastructure on top of TVM.

## Features
------------

*   Concise syntax for efficient development
*   Native code generation for optimized state-of-the-art performance
*   Automatic scheduling and synchronization for efficient use of resources
*   SIMD/SIMT vector programming for accelerating computations

## Notable Releases
------------------

*   Latest News: Ascend 950 backend support, Language Server Protocol implementation, and multi-backend language dialect release
*   2026-07-30: SM120 NVF4 block-scaled MMA addition and optimization
