# Former GitHub CEO launches competitor designed for the age of vibe coding

## Overview
- Thomas Dohmke, former GitHub CEO, founded **Entire**, a new Git‑hosting network aimed at supporting AI coding agents.
- The service positions itself as an “entirely new” platform that decentralizes Git hosting to relieve pressure on GitHub caused by AI‑driven traffic.
- Dohmke emphasizes that Git was designed for decentralization, but existing platforms have become centralized; Entire seeks to restore the original intent.

## Core Features
- **Mirroring**: Users on the waitlist (US, EU, Australia) can mirror public or private GitHub repositories to Entire.io, creating a parallel copy for AI agents.
- **Native Branches**: Projects can also use branches that exist only on the Entire network.
- **Entire CLI**: A Git‑integrated command‑line tool that records AI agent sessions, prompts, responses, and file changes, providing auditability of why code changes were made.
- **Scalability Claims**: Claims capacity of 2.1 million pushes per hour and 570 000 clone operations per hour, far exceeding competitor Cursor Origin’s reported figures.

## Business Model & Roadmap
- Offers Git hosting combined with agent‑auditing services.
- Plans to monetize data generated by AI agents and the “exhaust” useful to companies managing them.
- Intends to open‑source the Git network and enable self‑hosting in the coming months.

## Market Context
- Git remains dominant (≈ 94 % of developers) while GitHub faces infrastructure strain from AI coding agents.
- Competitors such as SpaceX’s Cursor Origin are also targeting the “agent‑friendly” niche.
- Entire’s positioning focuses on low‑latency, regional content control, and high concurrency to handle AI‑induced load.

## Future Vision
- Dohmke states the goal is to build an open, decentralized, independent developer ecosystem that serves both AI agents and human developers.
