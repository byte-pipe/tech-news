# A Flaw in ChatGPT’s Mac App Could Have Let Hackers Grab Sensitive Data | WIRED

**macOS ChatGPT Vulnerability Exposed**

A recently discovered vulnerability in the macOS version of OpenAI's ChatGPT exposes a potential attack vector for hackers and cybercriminals to compromise the AI software.

**Key Points:**

* A vulnerability in the macOS system allows attackers to access ChatGPT's chat logs and other data using a script interpreter.
* The script interpreter can be manipulated to deliver malicious commands into the main ChatGPT process.
* The vulnerability was "insanely trivial" to exploit, requiring only a dozen lines of code.
* Access to ChatGPT's chat logs and other data can be used to gain control over the app and its interactions.

**Additional Attack Vector:**

* Attacker(s) could use the script interpreter to access sensitive browser applications, such as the Safari browser, and potentially access sensitive information.
* Attackers could also use the script interpreter to run malicious commands, such as accessing other applications or files on the system.

**Insights:**

* The vulnerability is a result of the OpenAI platform's trust in the script interpreter, a trusted component within the ChatGPT app.
* The vulnerability suggests that AI software is not as secure as it seems, and hackers can exploit vulnerabilities in the underlying code to gain access to the app and its data.

**Mitigation:**

* OpenAI has publicly acknowledged the security flaw and is working to fix it.
* Researchers at the Objective-See Foundation are analyzing a number of AI macOS application bugs to provide further insights into these vulnerabilities.

**Impact:**

* The vulnerability raises concerns about the security and trustworthiness of AI software, particularly as its use proliferates more widely.
* Attackers could potentially leverage this vulnerability to gain access to sensitive data and compromise the app, further compromising the security of users and the broader ecosystem.
