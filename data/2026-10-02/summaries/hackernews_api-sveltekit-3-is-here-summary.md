# SvelteKit 3: A New Era of Adoption

## Key Features of SvelteKit 3

- **Migration Simplified**: A seamless migration experience is provided, including the use of `sv migratecommand` to automatically migrate existing codebases.
- **Enhanced Development Experience**: The framework features improved configuration, enhanced error handling, and a changed import style to `#lib`.
- **Powerful Configuration**: Configuration is now managed through `invite.config.ts` instead of `svelte.config.js`.
- **Easier Services**: Service workers are now less boilerplatey.
- **Improved Error Handling**: Error handling is improved across the board.
