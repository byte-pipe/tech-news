### Macro Workspace Overview

**Overview**: The Galactic Macro Worksystem (Macro) is an all-in-one workspace that unifies various tools and services for teams, providing a single interface with shared memory.

**Key Features:**

- Unified Communication Gateway: integrates email, chat, docs, tasks, agents, CRM into one fast interface
- Shared Team Memory: enables seamless switching between tool instances without data loss
- @Linked Files: search capabilities across folders and files
- Scalable Architecture: adaptable to team growth from 1 user to 20+

**Why Macro**: The development of Macro aimed to solve the limitations of existing software solutions, particularly Slack and Linear, which were found to be overly complex for small teams. Macro's architecture is designed with modularity in mind, allowing each block (e.g., communication tools) to be developed separately to facilitate easy extensibility.

**Key Statistics:**

- Designed by a team of ~15 developers over 2 years
- Built using SolidJS and Rust technologies for speed and reliability
- Aimed at small companies or teams with larger operations as their "operating system"
