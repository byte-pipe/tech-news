# How Claude marks AI-generated content | Claude Help Center

**Anthropic's Commitment to Transperency: How Claude Marks AI-Generated Content**

As a provider of generative AI models, Anthropic has signed the EU AI Act's Article 50(2) Code of Practice on Transparency of AI-Generated Content. This means that starting on August 2, 2026, new and existing Claude models will implement machine-readable marking to ensure transparency and signals about where content comes from.

**Key Features:**

* New models mark AI-generated content from day one
* Marking applies across supported platforms (Claude Platform, Claude, Code, Cowork, Tag)
* Watermarks embedded in generated text
* Provenance metadata included for files processed by Claude
* Cloud partners support:
	+ Embedded watermarks when accessed through AWS, Google Cloud, or Microsoft Foundry
	+ Signed provenance metadata where supported

**Limitations:**

* Not all platforms support certain marking types (e.g., embedded watermarks on specific partners)
* Transition period applies for models launched before August 2, 2026
