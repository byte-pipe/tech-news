**Kubernetes The Hard Way Tutorial**

**Overview**

This tutorial guides you through setting up a basic Kubernetes cluster from scratch using the core components. Unlike automated tools, this tutorial requires learning each step to ensure a thorough understanding of the process.

**Goal**

The primary goal is to learn the fundamentals of Kubernetes and how its core components work together.

**Target Audience**

The target audience is individuals looking to understand Kubernetes and its underlying components.

**Components**

The tutorial requires the following components to boot up a basic cluster:

* kubernetes v1.32.x
* containerd v2.1.x
* cniv v1.6.x
* etcd v3.6.x

**Network Required**

Four ARM64 or AMD64 based virtual or physical machines connected to the same network are required for the tutorial.
