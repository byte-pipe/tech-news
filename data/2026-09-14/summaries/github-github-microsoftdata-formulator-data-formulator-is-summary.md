## What is Data Formulator?
Data Formulator is an AI-powered data analysis system that makes it easy to connect, explore, and visualize data.

## Key Features

* Data connectors to link different data sources and data memory to store relationships
* Data Threads to branch into different questions, compare paths, and use visualizations to discover deeper insights
* A unified flow to automate the data analysis process
