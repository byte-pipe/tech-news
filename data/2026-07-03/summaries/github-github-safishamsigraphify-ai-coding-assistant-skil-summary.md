** safishamsi/graphify**

A GitHub AI coding assistant tool that maps your entire project into a knowledge graph, making it queryable instead of greping through files.

**Key Features:**

* Maps code, docs, PDFs, images, and videos into a knowledge graph
* Can be used for various programming languages, including Go, Python, R, etc.
* Provides a convenient way to navigate repository files

**Installation:**

1. Install the "graphifyy" package using isolated environment or alternatives like pipx and pip.
2. Run `uv tool install graphifyy` in your command-line interface.

**Main Files:**

* `graph/index.html`: The interactive graph view
* `GRAPH_REPORT.md`: A summary of key concepts, surprising connections, and suggested questions
* `graph.json`: The entire knowledge graph

**Prerequisites:**

* Python 3.10+
* Uv tool (installable via pipx or pip installation)
* Pipx alternative package for Windows

**Instructions:**

1. Install the "graphifyy" package using one of the recommended installs.
2. Run `uv tool install graphifyy` to install and update the uv tool.
3. Open a terminal and run `graphify` to access the interactive graph view.

Once set up, you can explore your project's code, docs, PDFs, images, and videos in an easy-to-use graphical interface.
