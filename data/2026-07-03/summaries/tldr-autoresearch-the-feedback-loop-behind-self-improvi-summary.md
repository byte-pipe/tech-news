# Autoresearch: The feedback loop behind self-improving agents

Here is a concise and informative summary of the article:

### Autoresearch: The Feedback Loop Behind Self-Improving Agents

**Introduction**

* The autoresearch framework, which involves building an "outer loop" where agents help maintain and improve the primary system using feedback signals, evals, and human input. This is in contrast to agent harnesses that focus on models only.

### Key Points from Roland Gavrilescu's Insights

* Autoresearch allows agents to take over aspects of maintenance and improvement without being bottlenecked by humans.
* The loop becomes the product: instead of focusing solely on modeling, autoresearch involves designing loops that agents can maintain in production environments.
* Three patterns have emerged:
  * **Autoresearch in Production**: focuses on harnesses instead of agent infrastructure from xAI.
  * **Agent Recipes and Skills**: allows agents to become more autonomous without generating additional slop. This involves developing a framework for "agent recipes" that provide guidance for complex processes.
