## Supabase Postgres Development Platform

### Introduction
Supabase is a public Postgres development platform built using enterprise-grade open source tools. It provides a dedicated database for building web, mobile, and AI applications.

*   **Features**: Authentication and Authorization, Auto-generated APIs/REST, GraphQL, Realtime subscriptions, Functions, Edge Functions, File Storage, Database Functions, Edge Functions, AI + Vector/Embeddings Toolkit
*   **Tools**: Open source Postgres database management system (hosted)
