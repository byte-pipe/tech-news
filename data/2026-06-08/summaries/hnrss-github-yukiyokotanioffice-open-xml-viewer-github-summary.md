# office-open-xml-viewer – GitHub Repository Summary

## Overview
- Browser‑based viewer for Office Open XML documents (DOCX, XLSX, PPTX) that renders onto an HTML Canvas.
- Parsers are written in Rust, compiled to WebAssembly; rendering uses the Canvas 2D API.
- Provides both a built‑in UI (via Storybook demo) and headless engines (`DocxDocument`, `XlsxWorkbook`, `PptxPresentation`) for custom UI composition.

## Installation
- npm: `npm install @silurus/ooxml`
- pnpm: `pnpm add @silurus/ooxml`
- Bundler notes:
  - Includes `.wasm` files; Vite needs `vite-plugin-wasm`, Webpack needs `experiments.asyncWebAssembly`.
  - Package is ESM‑only (`.mjs`). Import only needed format to keep bundle size small.
  - Math engine (~3 MB) is optional and located in `@silurus/ooxml/math`; it is tree‑shaken out if not imported.

## Quick Start Code Snippets
### DOCX (canvas supplied by caller)
```ts
import { DocxViewer } from '@silurus/ooxml/docx';
const canvas = document.getElementById('docx-canvas') as HTMLCanvasElement;
const docx = new DocxViewer(canvas);
await docx.load('/document.docx');
docx.nextPage();
```

### XLSX (viewer creates its own canvas and tab bar)
```ts
import { XlsxViewer } from '@silurus/ooxml/xlsx';
const container = document.getElementById('xlsx-container') as HTMLElement;
const xlsx = new XlsxViewer(container);
await xlsx.load('/workbook.xlsx');
```

### PPTX (canvas supplied by caller)
```ts
import { PptxViewer } from '@silurus/ooxml/pptx';
const canvas = document.getElementById('pptx-canvas') as HTMLCanvasElement;
const pptx = new PptxViewer(canvas);
await pptx.load('/deck.pptx');
pptx.nextSlide();
```

## Rendering Equations
- OMML equations in DOCX/PPTX are rendered with MathJax + STIX Two Math.
- The math engine is opt‑in: import from `@silurus/ooxml/math` and pass to the viewer.
- If not imported, equations are skipped and the ~3 MB engine is removed by tree‑shaking.
- XLSX has no equation support.

## Architecture Diagram (textual description)
- **Build‑time**: Rust source (`docx_rs`, `xlsx_rs`, `pptx_rs`) → `wasm-pack` → respective `.wasm` parsers.
- **Runtime (browser)**:
  - Shared core package `@silurus/ooxml-core` provides primitives (chart renderer, shape helpers, auto‑resize, types).
  - Each format package (`docx`, `xlsx`, `pptx`) contains:
    - Viewer API (`*Viewer`) handling canvas lifecycle and navigation.
    - Document/Workbook/Presentation model (`*Document`, `*Workbook`, `*Presentation`).
    - Web Worker (`worker.ts`) that loads the WASM parser and returns a JSON model.
    - Renderer (`renderer.ts`) that draws on the main thread using Canvas 2D.

## Loading Process
1. Web Worker initializes the appropriate WASM parser and parses the ZIP archive.
2. Worker posts a JSON representation of the document to the main thread.
3. Main thread renderer draws the content on the supplied canvas.
4. Rendering stays on the main thread to share the page’s `FontFaceSet`; off‑screen workers would have separate font registries.

## Key Files by Role
- `packages/docx/parser/src/lib.rs` – Rust parser for DOCX → JSON.
- `packages/xlsx/parser/src/lib.rs` – Rust parser for XLSX → JSON.
- `packages/pptx/parser/src/lib.rs` – Rust parser for PPTX → JSON.
- `packages/*/src/renderer.ts` – Canvas 2D rendering engines (main thread).
- `packages/*/src/worker.ts` – Web Worker that runs the WASM parser.
- `packages/*/src/viewer.ts` – Public Viewer API (canvas handling, navigation).
- `packages/core/src/index.ts` – Cross‑format primitives (chart renderer, shape helpers, auto‑resize, shared types).
