Mattermostis an open core, self-hosted collaboration platform that offers chat, workflow automation, voice calling, screen sharing, and AI integration. This repo is the primary source for core development on the Mattermost platform; it's written in Go and React, runs as a single Linux binary, and relies on PostgreSQL. A new compiled version is released under an MIT license every month on the 16th.

Deploy Mattermost on-premises, ortry it for free in the cloud.

Learn more about the following use cases with Mattermost:

* DevSecOps
* Incident Resolution
* IT Service Desk

* Download and Install Mattermost- Install, setup, and configure your own Mattermost instance.
* Product documentation- Learn how to run a Mattermost instance and take advantage of all the features.
