# GitHub - modular/modular: The Modular Platform (includes MAX & Mojo) · GitHub

**Repository Overview**

The Modular Platform is an open-source, unified platform for AI development and deployment, hosting theMAX Framework and Mojo language. The repo offers a wide range of components, including the Mojo compiler, standard library, accelerator library, and model pipelines.

**Components of the Platform**

* **MAX Framework**: A unified platform for deep learning and AI development.
* **Mojo Language**: A high-performance language for executing AI workflows.
* ** accelerator libraries**: Various libraries for accelerating and optimizing AI computations.
* **Model pipelines**: Graph-based frameworks for modeling and deploying AI models.
* **Code examples and documentation**: Extensive resources for developers, including code examples, documentation, and tutorials.

**Getting Started**

To start contributing to the Modular Platform, follow the contribution guide and documentation for working in the Max framework and codebase. Bug reports are also welcome.
