# OpenLogi

Here is a concise and informative summary of the text:

**Overview**

* OpenLogi is an alternative software solution for remapping keyboard, mouse, and camera buttons using HID (Human Interface Device) protocol.
* OpenLogi is developed in Rust and available as a standalone app, as well as for use with Logitech devices.

**Key Features**

* Remap keyboard, mouse, and camera button combinations using HID protocol
* Support for various Logitech devices, including MX Master 4 and Bolt Unifying/Unifying/Lightspeed devices
* Bindings are stored in a plain TOML file that is owned by the user
* Allows for custom shortcuts and app launchers
* Includes support for DPI control, SmartShift, and per-application profiles

**Technical Details**

* HID protocol is used for device communication
* Remap functionality works with up to 44 built-in actions
* DPI control and SmartShift are implemented using custom firmware on HID++ chip
* Per-application profiles and device rendering are available for macOS, Linux, and Windows

**Installation**

* Download OpenLogi app using `.dmg`, `.deb`, or `.rpm` package manager
* Choose platform (macOS, Linux, or Windows) and download signed builds
* No account or telemetry required
