# Crafting Apps: open-source creative tools — ArtCraft

## Overview
- A suite of seven native, open‑source creative applications built entirely in Rust.
- Targets image editing, vector illustration, video editing, photography, PDFs, motion graphics, and page layout.
- All apps are free to use and available for macOS, Windows, Linux, and (for most) WebAssembly in browsers.
- Community interaction and development happen on the ArtCraft Discord and GitHub.

## The Lineup
- **PhotoCraft** – image editor, early alpha, installers for macOS, Windows, Linux, and Web.
- **VectorCraft** – fast vector illustration tool, currently in development for all desktop platforms and Web.
- **FilmCraft** – professional video editor, being rebuilt from scratch in Rust, desktop‑only development.
- **LightCraft** – photo library and raw developer, in development for desktop and Web.
- **PrintCraft** – PDF workbench for reading, organizing, combining, splitting, and securing PDFs, early alpha, desktop and Web.
- **EffectCraft** – motion graphics and visual effects suite, in development for desktop and Web.
- **DesignCraft** – page layout and publishing application, in development for desktop and Web.

## Core Principles
1. **Open source** – every line of code is on GitHub under permissive licenses; users can read, fork, and extend.
2. **Native, not wrapped** – pure Rust compiled to native desktop binaries; no Electron or embedded web views.
3. **Familiar from day one** – layouts, tools, and shortcuts match professional standards to avoid relearning.
4. **Your files, your machine** – all processing runs locally; no cloud round‑trips.
5. **Agent‑ready** – each app can be driven via CLI, JSON control channel, or MCP server for automation and AI agents.
6. **Also in your browser** – most apps compile to WebAssembly and run in a browser tab.

## Community & Development
- Early builds, roadmaps, and contributor discussions are hosted on the ArtCraft Discord.
- Users are invited to suggest new crafts, test pre‑release versions, and follow development progress.
