# GitHub - google-gemini/gemini-cli: An open-source AI agent that brings the power of Gemini directly into your terminal. · GitHub

**Gemini CLI Overview**
=====================

Gemini CLI is an open-source AI-powered terminal access tool that provides direct access to Google's AI models, allowing users to interact with them from their terminal.

**Key Features**
---------------

* Quick installation using `npx` or `npm`
* Supports installation as a global package
* Available in multiple platform builds (macOS, Linux, macOS with Homebrew, and macOS with MacPorts)
* Supports Anaconda for restricted environments
* GitHub repository provides documentation, releases, and a blog post on its history and roadmap

** Installation Process**
-----------------------

1. Quick Install: Run `npx @google/gemini-cli` or `npm install -g @google/gemini-cli`.
2. Install globally: Run `npm install -g @google/gemini-cli` or `brew install gemini-cli` or `conda install -c conda-forge nodejs`.
3. Install as a specific environment: Run `conda create -y -n gemini_env -c conda-forge nodejs` or `brew install -c homebrew gemini-cli`.
