**Overview of Cindy**

Cindy is an open-source AI agent that works out of the box and can integrate multiple harvests, models, and tools into one agent. It is designed to handle real work in projects and apps, and can be used locally or remotely.

**Key Features and Benefits**

* Cindy runs locally on the user's machine, using the user's files and logged-in apps.
* It supports multiple harnesses, such as Claude Code and Codex, which can be used to complete tasks simultaneously and review different combinations.
* Cindy allows users to share models and harnesses with others, and can even drive browser, computer, and phone work.
* The client is open-source, free to use, and has a source code hosted under Apache-2.0.
* Users can sign in to the official Cindy service and use models in-app.

**Use Cases and Setup**

* Linux users can follow the installation guide for Ubuntu, Arch Linux, and Omarchy.
* Cindy provides documentation on deployment, updates, and key management.

**Goals and Next Steps**

* Cindy aims to be free to use and source code under Apache-2.0.
* Future enhancements include native harnesses and multi-harness switching.

**Note**

* This repository is available for download and is hosted on GitHub.
