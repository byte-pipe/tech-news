# Microsoft open‑sources “the earliest DOS source code discovered to date”

## Release details
- Microsoft has published source code that predates the MS‑DOS brand.
- The release includes:
  - The 86‑DOS 1.00 kernel source.
  - Several development snapshots of the PC‑DOS 1.00 kernel.
  - Utilities such as CHKDSK.
- The code was originally stored on paper printouts and has now been digitized.

## Historical context
- 86‑DOS (initially called QDOS) was created by Tim Paterson for a Seattle Computer Products 8086 kit.
- Microsoft licensed 86‑DOS to supply an OS for the IBM PC 5150, hired Paterson to continue development, and later bought the rights outright.
- Microsoft marketed the OS as MS‑DOS, while IBM sold it as PC‑DOS; widespread IBM‑compatible clones made MS‑DOS the dominant version.

## Preservation effort
- A team called the “DOS Disassembly Group,” led by Yufeng Gao and Rich Cini, transcribed and scanned the paper code.
- Modern OCR tools struggled with the low‑quality printouts, requiring painstaking manual work.

## Earlier open‑source releases
- Microsoft previously open‑sourced MS‑DOS 1.25 and 2.0 (2014, 2018) and MS‑DOS 4.0 (2024) in the same GitHub repository.
- Other early projects released include the game Zork and its sequels, Microsoft 3D Movie Maker (1995), and a remake of the MS‑DOS editor.

## Recent rediscoveries
- Two years ago the earliest known version of 86‑DOS was found and uploaded to the Internet Archive, marking a continued interest in early PC history.
