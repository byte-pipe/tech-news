# Summary of Anthropic’s Planned Claude Memory Update with “Memory Files”

## Key Changes
- Anthropic is redesigning Claude’s cross‑session memory, introducing a dual‑mode system:
  - **Classic** – the current single‑summary note approach.
  - **Memory Files** – a new file‑based architecture that stores notes in multiple structured documents.
- Users will be able to choose between the classic mode and the Memory Files mode.

## How Memory Files Work
- Claude creates organized notes during conversations and stores them in separate files grouped by topic, project, or context.
- The system functions like a personal wiki, allowing Claude to retrieve only the relevant files for a given discussion.
- This file‑based memory mirrors the approach used in always‑on agents such as OpenClaw and Hermes, enabling a larger, more durable record without exceeding the context window.

## “Dreams” Feature
- “Dreams” is an asynchronous, scheduled process that runs over the accumulated Memory Files.
- It merges duplicate entries, updates stale information, resolves contradictions, and highlights patterns missed during live chats.
- Anthropic likens Dreams to REM‑sleep consolidation: the original store stays unchanged while a reorganized version is produced for review.
- Currently in limited beta on the developer platform, scoped to Opus 4.7 and Sonnet 4.6.

## Related Developments
- **Claude Conway agent** is expected soon; Memory Files may be part of its preparation.
- Smaller UI tweaks are also being prepared alongside the memory overhaul.
- The update aims to give Claude a more competitive persistent‑memory capability while keeping user control over retained data.

## Timeline and Impact
- No firm release date has been announced.
- The memory rework is considered the most consequential upcoming change, positioning Claude against rival persistent‑memory architectures.
