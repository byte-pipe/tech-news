# Summary of “This Buried Apple Feature Turns an iPhone Into the Perfect Kids’ Dumb Phone | WIRED”

## Background
- The author needed a phone for his young son that allows calls, texts, navigation, and tracking but blocks internet browsing and social media.
- Traditional iOS parental controls cannot fully block Safari, and work‑arounds (e.g., opening links from messages) exist.
- Third‑party “dumb‑phone” apps charge for removing apps, which the author found illogical.

## The Hidden Feature: Assistive Access
- Introduced in iOS 17, originally intended for users with cognitive disabilities.
- Provides a simplified interface with large tiles, limited options, and the ability to whitelist specific apps.
- Internet‑enabled apps (Safari, Chrome, etc.) can be omitted entirely, preventing accidental web browsing.

## How to Set It Up
1. Open **Settings → Accessibility → Assistive Access**.  
2. Tap **Set Up Assistive Access** and choose a grid layout for large tiles.  
3. Select the apps to allow (green “+” icon).  
4. Configure additional options:  
   - Call permissions (everyone, contacts only, favorites).  
   - Show time on lock screen, mute switch behavior, notification style, etc.  
5. Set a unique four‑digit Assistive Access passcode.  
6. Activate/deactivate by triple‑clicking the side or Home button and entering the passcode.

## Chosen Configuration for the Author’s Son
- Allowed apps: Calls, Messages, Maps, Camera (video‑call only), Photos, Music.  
- Safari and other browsers are excluded, so links appear as plain text.  
- Future additions (e.g., Wallet) can be enabled with a single setting change.

## Benefits
- Turns an old iPhone into a six‑app “dumb phone” without extra cost.  
- Retains essential features: FaceTime, Find My, navigation, and parental control over contacts.  
- No workaround exists without the Assistive Access passcode; the child cannot access Settings or install new apps.  
- Seamlessly integrates with the family’s Apple ecosystem.  
- Apple Store staff praised it as a superior alternative to Screen Time.

## Limitations
- The Assistive Access interface can feel sluggish.  
- Early versions ignored existing Screen Time limits; iOS 26 (2025) later aligned them.  
- Voicemail is disabled, requiring reliance on text messages for missed calls.  
- The device cannot be powered off while in Assistive Access mode; it must be switched back to normal iOS first.

## Outlook
- Apple’s upcoming Screen Time overhaul in iOS 27 (September) will adopt some Assistive Access capabilities, such as the ability to block Safari for child profiles.  
- The author suggests Apple could market Assistive Access more prominently or develop a dedicated kids’ OS version.
