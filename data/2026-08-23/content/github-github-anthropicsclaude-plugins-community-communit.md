# Claude Plugins — Community

Community-contributed plugins forClaude CoworkandClaude Code.

## What this repo is

Aread-only mirrorof the community plugin marketplace. The.claude-plugin/marketplace.jsonfile here is the list of community plugins available to install. It is synced nightly from Anthropic's internal review pipeline.

Every plugin listed here has been submitted viaclaude.ai, passed automated security scanning, and been approved for distribution.

## Using this marketplace

### Claude Cowork

Install plugins fromclaude.com/plugins.

### Claude Code

claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install
