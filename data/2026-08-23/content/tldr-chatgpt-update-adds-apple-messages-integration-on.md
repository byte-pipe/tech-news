# ChatGPT update adds Apple Messages integration on Mac

 

Zac Hall
 | Aug 20 2026 - 10:59 am PT																

Well, this seems interesting. ChatGPT’s latest update adds a new Mac integration: the ability to work with conversations from Apple’s Messages app. The feature works with iMessage, SMS, and RCS.

## ChatGPT for Mac now includes an Apple Messages plugin

The new Apple Messages plugin lets ChatGPT read and search chats on a Mac, and prepare and send messages.

OpenAI says it is available across all plans in the ChatGPT desktop app for macOS, with support in both ChatGPT Work and Codex.

That access raises privacy and control questions, so OpenAI stresses that sending remains gated by user approval under the default settings.

Users should take care before granting persistent approval. OpenAI’s plugin guide details the risks and how to revoke access.

It also lists a known issue involving tasks that disable approval prompts: “If your task is set to Full access or otherwise disables approval prompts, Apple Messages may be unable to show the confirmation needed to send. Switch to Ask for approval or Approve for me and try again.”

## How OpenAI’s Messages plugin works on the Mac

OpenAI explains that the optional Messages plugin runs locally on the Mac. Like other ChatGPT/Codex features including Computer Use, it relies on macOS system technologies like AppleScript and Accessibility.

The optional Messages plugin is not like the sketchy server-related hacks that try to bring iMessage functionality to Android. It’s simply using files on your Mac with your permission when prompted.

And unlike Siri AI, it doesn’t rely on an index of content from Messages. ChatGPT for Mac only uses the data when directed and with permission.

As you can see below, once enabled by the user, ChatGPT is super clear in what it does with messages, especially sending on your behalf when asked.

For these reasons, it shouldn’t be a privacy concern for Apple. The data exists as files on your Mac, and you need to give ChatGPT permission to work with the files. OpenAI also isn’t the only AI company to develop similar tools. It’s just a benefit of the Mac being a more capable operating system than mobile platforms.

You can use the plugin in ChatGPT Work and Codex. By default, ChatGPT sends messages only after you approve the message and its recipients. Separately, OpenAI details how the Messages feature works onits dedicated plugin site:

The Apple Messages plugin is available on all plans in the ChatGPT desktop app for macOS. In Codex and ChatGPT Work, it can read and search iMessage, SMS, and RCS chats on your Mac and send messages on your behalf through the Messages app. It doesn’t let you interact with ChatGPT remotely through Messages, and it doesn’t work in regular ChatGPT chats.

## Site co-editing, shared thread snapshots, and more

While the Messages plugin is the standout addition for Apple users, the release includes several other improvements. For example, pinned chats now stay in sync across the ChatGPT desktop app and iOS, so users can keep important conversations accessible between a Mac and iPhone.

ChatGPT also now lets users share a read-only snapshot of a local Codex thread. These snapshots do not change as the original thread evolves.
