# Figma product news and release notes

# Figma Product News and Release Notes Summary

## Aug 14 2026 – Responsive text with Text Wrap
- Introduces two new wrap options for text layers, styles, or paragraphs:  
  - **Balance** – distributes text evenly across lines.  
  - **Pretty** – prevents a single word from being stranded on the last line.  

## Aug 13 2026 – Community skills and the Figma Agent
- Adds a library of 50+ AI skills in the Figma Community for design workflows.  
- Users can ask the Figma Agent to create a skill from file context and invoke it directly.  
- Created skills can be published to the Community for others to try or remix.  

## Aug 11 2026 – Figma MCP: Run Weave tools from any agent
- Enables running Figma Weave tools through agents such as ChatGPT, Claude, or Cursor via the MCP server.  
- Benefits: stay in‑flow without switching apps, retain full context (prompts, images, brand guidelines), and receive results directly in the conversation.  
- Future update: build new Weave workflows without leaving the agent.  

## Aug 5 2026 – AI credit limits and requests
- Admins can set custom AI‑credit limits per user.  
- When a limit is reached, users may request an increase from their admin.  

## Aug 3 2026 – Nested folders replace Projects
- Projects are renamed to Folders; all team files now live in folders.  
- Supports nesting up to 10 layers deep with optional color tags for hierarchy.  
- Sharing inherits access from parent folders, with options to restrict specific users.  
- Rollout to all plans over the coming weeks.  

## Jul 30 2026 – New editing panel in Figma Make
- Provides granular control over spacing, type, and layout with stacked edits visible in a chat‑style panel.  
- Annotations let users describe intent (e.g., “make this section feel calmer”) for direct agent changes.  
- Allows preview across device frames while editing and adds a shortcut in the toolbar.  

## Jul 24 2026 – Updated Auto Layout closer to CSS
- Aligns Auto Layout behavior with CSS, reducing handoff workarounds.  
- Existing frames stay on the legacy version unless manually updated; new frames use the updated version automatically.  
- Legacy mode remains available until January 2027.  

## Jul 16 2026 – Code‑backed screens with attached variables
- When importing code‑backed screens, colors, typography, and spacing bind to existing file variables instead of becoming hard‑coded values.  
- Applies to Make previews copied onto the canvas and designs generated via the Figma MCP.
