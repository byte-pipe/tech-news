# Introduction

## Overview
- Slumber is a terminal‑based HTTP client designed for interacting with REST and other HTTP services.  
- It offers two modes of operation:
  - **Terminal User Interface (TUI)** – interactive request/response handling, considered the most useful.
  - **Command Line Interface (CLI)** – quick requests and scripting capabilities.  

## Goals
- Easy to use.  
- Configurable.  
- Sharable.  

## Configuration
- Settings are stored in a YAML file named **the request collection**.  
- Both TUI and CLI share this same configuration format.
