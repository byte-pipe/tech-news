# Anthropic, Microsoft in talks about Maia AI chip deal

## Key Points
- Anthropic is currently discussing the use of Microsoft’s custom Maia AI chip, but no agreement has been finalized.  
- Microsoft unveiled the second‑generation Maia chip in January; it has not yet been offered to Azure customers.  
- Anthropic’s CEO Dario Amodei has noted recent “difficulties with compute,” increasing the urgency for new hardware.  

## Background
- A partnership would give Microsoft a foothold in the AI‑silicon market, where Amazon and Google currently lead.  
- Microsoft announced that the Maia 200 processor can run OpenAI’s upcoming GPT‑5.2 model.  
- In November, Microsoft pledged a $5 billion investment in Anthropic, while Anthropic committed $30 billion in Azure spend, though it also uses Amazon and Google cloud services.  

## Recent Developments
- Anthropic plans to pay $1.25 billion per month to SpaceX for computing power through May 2029.  
- Historically, Anthropic has relied on NVIDIA GPUs, AWS Trainium chips (in a 10‑year, >$100 billion deal), and Google’s Tensor Processing Units.  
- Microsoft’s Satya Nadella stated that the Maia 200 offers over 30 % better tokens‑per‑dollar than the latest silicon in Microsoft’s fleet; the chips are already operating in data centers in Arizona and Iowa.  

## Outlook
- A finalized Maia chip agreement would strengthen Microsoft’s position in AI hardware and address Anthropic’s growing compute needs for its Claude assistant and Claude Code programming tool.
