**opengeos Geolibre Overview**
======================================================

**Key Points**

* A lightweight, cloud-native GIS platform for visualizing, exploring, and analyzing geospatial data
* Runs everywhere, including web browser, desktop, mobile, and Jupyter notebooks
* Built with Tauri v2, React, TypeScript, MapLibre GL JS, DuckDB-WASM Spatial, and deck.gl
* Platform is open-source and free
