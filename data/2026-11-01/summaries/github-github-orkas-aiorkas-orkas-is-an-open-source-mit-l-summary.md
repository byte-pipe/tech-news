# Orkas – Open‑source Local‑First AI Team

## Overview
- Orkas is a free, MIT‑licensed desktop application (macOS & Windows) that coordinates a team of AI agents to turn user goals into completed work.  
- It operates locally; all data stays on the user’s computer.  
- The app includes 16 built‑in specialist agents and can integrate additional agents (Claude Code, Codex, OpenCode, OpenClaw, Hermes) or user‑provided API keys (Claude, OpenAI, Gemini, DeepSeek, Kimi, GLM, Qwen, MiniMax, Doubao, or a local OpenAI‑compatible endpoint).  

## Core Concepts
- **Project** – stores goal, rules, memory, and files so each conversation continues from the previous state.  
- **To‑do list & Auto‑advance** – tasks are assigned to people or agents; with Auto‑advance enabled the team automatically picks the next item and returns results for review.  
- **Scheduled automations** – repeatable tasks can run hourly, daily, weekly, or monthly; missed runs are caught within 12 hours after the computer wakes.  
- **Connectors** – built‑in integrations for Gmail, Google Calendar, Sheets, Drive, Notion, Slack, Shopify, Stripe, etc.; actions require user confirmation.  
- **Apps & Shared projects** – describe a tool and Orkas creates a local app; packaged versions allow sharing projects, cloud sync, and publishing web apps (paid plans).

## Example Capability: Reference Video Recreation
- VideoStudio can ingest a reference video and user assets, analyze narrative structure, visual beats, and call‑to‑action, then propose a production plan that preserves the hook and pacing while swapping in the new content.  
- Best suited for motion‑graphic explainers, SaaS demos, and product ads.  
- Requires a local video file; social‑platform links are not supported.  

## Getting Started
- Download the free desktop app (includes 500 credits for the built‑in Orkas model).  
- Users may configure their own API keys in Settings → Models; voice input is supported in the source build.  

## Limitations
- Shared projects, cloud sync, and web‑app publishing are only available in the packaged (binary) version; the open‑source repository does not yet provide these features.
