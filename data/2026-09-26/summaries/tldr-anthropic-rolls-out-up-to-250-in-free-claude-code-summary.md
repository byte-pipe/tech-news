# Anthropic rolls out up to $250 in free Claude Code credits, but only for cloud sessions

## Main announcement
- Anthropic now lets users run Claude Code via cloud sessions without joining the research preview.  
- Eligible subscribers receive promotional credits: **$100** for Pro plans, **$250** for Max plans.

## How cloud sessions work
- Runs Claude Code on Anthropic‑hosted infrastructure, allowing tasks to continue when the user’s computer is off.  
- Can be started from claude.ai/code, the Claude mobile app, the desktop app, or the CLI (`claude --cloud`).  
- Credits are applied automatically and are separate from regular Claude usage limits.  
- After the promotional balance is used, cloud sessions count toward the user’s normal plan limits; there is no extra charge for the cloud container itself.

## Claiming the credits
- Offer is available to individual Pro and Max subscribers who had an active subscription when the promotion began on September 23.  
- Credits must be claimed on Claude’s website by **October 7**; any remaining balance expires on **November 4**.  

## Additional notes
- The promotion encourages existing subscribers to try cloud sessions; if local limits are reached, users can continue work in the cloud until credits run out.
