# Windows 11½ – Parody Overview  

## What the project is  
- An unofficial, independent parody of Microsoft Windows, titled “Definitely Not Windows / Windows 11½”.  
- Created for humor, satire, and commentary; not affiliated with, endorsed by, or sponsored by Microsoft.  

## Core satire themes  
- Mocking modern software practices: endless subscriptions, intrusive ads, AI assistants, frequent updates, storage warnings, and forced default‑browser changes.  
- Exaggerated UI elements (Clippy 365, “Totally Normal Video”, fake store recommendations) that pretend to install apps, sell subscriptions, or break the system.  

## Key features presented (parodic)  
- **Clippy 365** – a visitor‑ledger that assigns a random anonymous ID and a persistent visitor number, stored locally without personal data.  
- Fake Office apps (Word, Excel, Outlook, Teams) that display subscription prompts, disabled editing, and absurd expense tables.  
- “Copilot” assistant offering over‑the‑top help, with options that humorously worsen the situation.  
- Parodied system menus: Settings, Task Manager, OneDrive, Recall, Windows Update, Recycle Bin, etc., all with tongue‑in‑cheek messages.  

## Legal and disclaimer notes  
- Trademark notice: all product names (Microsoft, Windows, Edge, etc.) belong to their owners and are used solely for parody.  
- Explicit statements that no real Microsoft credentials, passwords, or credit cards are required or requested.  
- Buttons and dialogs are non‑functional; any “install”, “update”, or “purchase” actions are purely simulated.  

## User experience highlights  
- Persistent “visitor counter” that treats returning browsers as “suspiciously familiar new persons”.  
- Satirical prompts such as “Your storage is full” (while real storage is fine) and “Upgrade to calculate” in Excel.  
- Mock advertisements for services like Temu, Solitaire Collection, and Microsoft 365, poking fun at monetization.  

## Overall purpose  
- To provide a comedic, self‑aware imitation of a Windows desktop that critiques the direction of contemporary operating‑system ecosystems.  
- Encourages users to recognize the absurdities of subscription‑driven software and invasive UI elements through exaggerated parody.
