# Introducing dots – summary

## Overview
- Dots are always‑on AI agents powered by GPT‑6 Astra, equipped with their own cloud computer.
- They learn from feedback, work 24/7 toward user goals, and connect to over 4,000 apps via plugins.
- Accessible through ChatGPT, Slack, Teams, and voice calls, they adapt to individual preferences and work styles.

## Core capabilities
- Operate independently using a dedicated cloud browser and compute resources.
- Can be granted permission to use the user’s laptop or other devices.
- Manage multiple projects simultaneously and allow users to add new tasks without juggling threads.
- Proactive research runs in the background on read‑only data from connected apps.

## Typical use cases
- **Developer:** monitors feedback, scopes fixes, builds and tests PRs, delivers video demos for review.
- **Product launch lead:** updates positioning, assets, and documentation when scope changes.
- **Scientist:** reruns analyses with new data, revises figures, flags results needing review.
- **Sales lead:** checks requirements, builds proofs of concept, suggests engineers, updates proposals.
- **Content creator:** extracts clips, drafts show notes and social posts, learns voice and audience preferences.

## Integration & access
- Interact via messaging or calls in ChatGPT (desktop, web, mobile), Slack, and Teams; texting support is forthcoming.
- Context follows the dot across all channels, keeping a unified view of the project.
- Users control which apps the dot can access through existing ChatGPT app settings and can set custom permission rules.

## Control and safety
- Each dot runs in an isolated cloud environment; user data stays on the user’s device unless explicitly shared.
- Built‑in safeguards prevent malicious instructions, enforce safety requirements, and can pause or stop work if concerns arise.
- Auto‑review checks actions against user instructions, custom rules, and safety policies before execution.
- Users decide whether dot conversations are used to improve models; proactive research notes are not directly used for training.

## Availability and roadmap
- Initially rolled out to Pro, Business Premium, and Enterprise plans in eligible markets.
- Plans to expand to more users and introduce specialist dots with dedicated identities for IT‑provisioned hardware and deep system integrations.
