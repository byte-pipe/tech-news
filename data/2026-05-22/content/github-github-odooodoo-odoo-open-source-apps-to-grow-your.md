# Odoo

Odoo is a suite of web based open source business apps.

The main Odoo Apps include anOpen Source CRM,Website Builder,eCommerce,Warehouse Management,Project Management,Billing & Accounting,Point of Sale,Human Resources,Marketing,Manufacturing,...

Odoo Apps can be used as stand-alone applications, but they also integrate seamlessly so you get
a full-featuredOpen Source ERPwhen you install several Apps.

## Getting started with Odoo

For a standard installation please follow theSetup instructionsfrom the documentation.

To learn the software, we recommend theOdoo eLearning,
orScale-up, the business game.
Developers can start withthe developer tutorials.
