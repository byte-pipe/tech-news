# Summary of “Anthropic’s Code with Claude showed off coding's future—whether you like it or not”

## Event overview
- Code with Claude was a two‑day developer conference in London that started on May 19, the same day as Google I/O.  
- The venue was packed; many participants coded on laptops while listening to talks.

## Adoption of Claude for pull requests
- Jeremy Hadfield asked the audience how many had shipped a pull request written entirely by Claude; about half raised their hands.  
- He followed with a question about not reading the generated code at all, and most hands stayed raised.

## Evolution of Claude Code
- Claude 4 could code modestly; updates Claude 4.6 (February) and Claude 4.7 (April) made Claude Code far more reliable.  
- Anthropic’s aim is maximal automation: Claude prompts itself, tests, and fixes its own output without human intervention.  
- Boris Cherny described the default workflow as “let Claude prompt itself.”  
- Ravi Trivedi summed it up with the principle “Let it cook.”

## New “dreaming” feature
- Claude Code agents write self‑notes about tasks; later agents read those notes to get up to speed.  
- The “dreaming” system consolidates notes, spots patterns, and learns from errors across a codebase, improving future performance.

## Success stories and industry adoption
- Companies that have reorganized around Claude Code presented at the event, including Spotify, Delivery Hero, Lovable, Base44, and Monday.com.  
- Attendees showed enthusiasm; no visible dissent was observed at the conference.

## Criticisms and concerns
- Online discussions on Reddit and Hacker News raise issues such as:
  - Managers pushing AI for productivity while developers face more code to review.  
  - Developers feeling their coding skills deteriorate.  
  - AI‑generated code potentially introducing security vulnerabilities.  
- In interviews, Claude engineering lead Katelyn Lesse and product lead Angela Jiang responded:
  - Traditional software‑development best practices still apply.  
  - Some technical managers feel overwhelmed by the volume of AI‑generated code.  
  - Claude currently performs at roughly a mid‑level engineer’s ability; expert engineers remain essential for system design and hard problems.  
  - The long‑term vision is for Claude to eventually be able to build itself.
