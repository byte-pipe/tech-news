# ChatGPT Ads Business Agent Conversation Campaign Type

## Overview
- OpenAI is testing a new ad campaign type called **Agent** that directs ChatGPT users to a Business Agent conversation instead of a traditional website landing page.  
- The information was shared by Juozas Kaziukėnas on LinkedIn; the feature is currently available only to select advertisers and is not visible in all accounts.

## How the Agent Campaign Works
- **Website Scraping:** OpenAI crawls the advertiser’s website to create a business profile, extracting common customer questions, support details, and overall context.  
- **Business Agent Creation:** Advertisers configure a business agent with specific instructions, leveraging the scraped profile, product feeds, and MCP tools for data access. The agent can also capture leads via custom forms.  
- **Ad Launch:** The ad points to the business agent rather than a URL, initiating a chat experience that uses the same underlying technology as custom GPTs.

## Current Availability
- In the Ads Manager, only “standard” and “product feeds” campaign types are visible for most users; the “Agent” option is not yet broadly released.  
- Juozas confirmed the feature exists in the Ads Manager for a limited set of advertisers, but the exact user experience remains unconfirmed.

## Industry Context
- Business agents are not a new concept in AI or search advertising; Google previously introduced similar functionality with its own local service ads.  
- OpenAI’s approach represents a shift toward chatbot‑native advertising, allowing more interactive and context‑aware user engagements.
