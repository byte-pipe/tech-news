### Astryx: An Open Source Design System

Astryx is an open source design system built by Meta over the last eight years. It provides a customizable and agent-ready platform for building user interfaces, powering applications, and guiding product teams. The system combines 150+ accessible components, brand-level theming, dark mode, ready-to-ship templates, and a CLI as one cohesive system.

**What sets Astryx apart:**

* **Open design**: Components are built at any level, allowing for flexibility and customization.
* **No styling lock-in**: Styles can be overridden using custom CSS classes or libraries (e.g. Tailwind, CSS modules).
* **Customization without wrapping:** Themes provide pre-built CSS customizations that consumers can easily adopt.
* **Built for collaboration**: Astryx is designed to work seamlessly with people and AI assistants, from the same reference.
