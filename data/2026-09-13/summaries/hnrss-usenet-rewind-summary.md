# Usenet-Rewind Summary

## Overview
- Usenet-Rewind is a research archive that stores Usenet newsgroup conversations from 1981 to the present.
- It captures early internet content such as tech support, software debates, scientific discussions, hobbyist communities, entertainment commentary, and historical accounts of the web’s development.

## Main Features
- **Search**: Allows users to query the archive by title/subject, body text, author, message ID, newsgroup, and date range.
- **Browse**: Provides navigation through all available newsgroups.
- **Resources**: Offers additional Usenet‑related tools and references.
