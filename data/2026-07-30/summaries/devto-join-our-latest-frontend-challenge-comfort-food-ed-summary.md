# Summary of Frontend Challenge: Comfort Food Edition

## Overview
- The challenge runs from July 29 to August 16, inviting developers to create frontend projects inspired by comfort food.
- Participants can showcase dishes, restaurant sites, recipes, or regional foods using CSS, JavaScript, or other web technologies.
- Submissions are posted on DEV with the required `#frontendchallenge` tag and can include embedded projects.

## Prompts
### CSS Art: Comfort Food
- Build a visual piece primarily with CSS (e.g., ramen bowl, pancakes, pie slice).
- Light JavaScript is allowed but the focus remains on CSS craftsmanship.
- Use the provided CSS Art Submission Template.

### Perfect Landing: Comfort Food
- Create a polished landing page with a food theme (real or imagined restaurant, recipe collection, food festival, etc.).
- Any browser‑compatible language (JavaScript, TypeScript, Dart, WebAssembly, etc.) may be used.
- Use the Perfect Landing Submission Template.

## Judging Criteria & Prizes
- **CSS Art**: creativity, effective CSS use, aesthetic outcome.
- **Perfect Landing**: accessibility, usability/UX, creativity, code quality.
- Winners of each prompt receive a DEV++ Membership and an exclusive DEV Badge.
- All participants with a valid submission earn a completion badge on their DEV profile.

## How to Participate
- Publish a post using the appropriate submission template and include the `#frontendchallenge` tag.
- You may submit to one or both prompts; multiple entries per prompt are allowed (separate posts).
- Embed your project directly (e.g., Google Cloud Run, CodePen) to enhance the post.
- Review the judging criteria, rules, guidelines, and FAQ before submitting.

## Important Dates
- **July 29**: Challenge begins.
- **August 16, 11:59 PM PDT**: Submission deadline.
- **September 10**: Winners announced.
