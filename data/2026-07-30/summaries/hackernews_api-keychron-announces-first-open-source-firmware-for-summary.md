# Keychron announces first open‑source firmware for gaming mice

## Overview
- Keychron introduced **ZGM**, an open‑source firmware for its upcoming G6 HE hybrid magnetic switch gaming mouse, slated for release in Q1 2027.  
- ZGM aims to bring the flexibility of keyboard projects like QMK/ZMK to gaming mice, a domain where open‑source firmware is rare.

## Main Features
- Low‑latency operation tailored for gaming performance.  
- Modular layer system covering sensor, buttons, scroll wheel, and lighting.  
- Compatibility with a wide range of microcontrollers and both wired and wireless configurations.  
- Firmware resides in the mouse’s internal memory, eliminating the need for background software.

## Context and Significance
- Follows Keychron’s earlier open‑source keyboard initiative, which released firmware and CAD files to the community.  
- Few manufacturers (e.g., Wooting) have shared similar permissive‑license resources; major brands like Razer or Logitech have not.  
- Success could position ZGM as a standard for boutique gaming mice, similar to QMK’s role in mechanical keyboards.

## Development Status
- The project is in an early setup phase, with public development and community feedback encouraged.  
- Hosted on GitHub under the GNU General Public License, providing access to goals, documentation, and source code.  

## Outlook
- Community interest will determine whether ZGM achieves widespread adoption and influences future mouse firmware practices.
