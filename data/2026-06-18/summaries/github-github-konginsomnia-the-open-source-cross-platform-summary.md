# Kong/insomnia API Client Overview

## Key Points:

* Kong is an open-source API client for various protocols and formats, including GraphQL, REST, WebSockets, Server-Sent Events (SSE), gRPC, and others.
* Insomnia is a popular API client that provides a native OpenAPI editor and visual preview for designing APIs.
* The platform offers multiple storage options, including Local Vault, Git Sync, and Cloud Sync.

## Features:

* Debug APIs using the most popular protocols and formats
* Design APIs with the native OpenAPI editor and visual preview
* Test APIs with native test suites and collection runner
* Mock APIs with a cloud or self-hosted mocking server
* Build CI/CD pipelines with the Insomnia CLI for linting and testing
* Collaborate with others using various collaboration features
* Include the ability to use 3rd party plugins

## Storage Options:

* Local Vault: 100% local storage of collections, design specs, and other resources
* Git Sync: Git storage using any 3rd party Git repository without going through cloud
* Cloud Sync: cloud-based collaboration with optional end-to-end encrypted (E2EE) in the cloud

## Getting Started:

Insomnia is available for Mac, Windows, and Linux. Download the platform from [https://insomnia.rest](https://insomnia.readthedocs.io).

## Account and Subscriptions:

Kong/insomnia offers a free version without an account. However, with an account, you can unlock full capabilities and access to storage options.
