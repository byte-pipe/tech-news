# GitHub - biomejs/biome: A toolchain for web projects, aimed to provide functionalities to maintain them. Biome offers formatter and linter, usable via...

**Biomejs Overview and Key Features**

* **A performant toolchain for web projects**
* Provides developer tools to maintain project health
* Supports JavaScript, TypeScript, JSX, JSON, CSS, and GraphQL code styles
* 97% compatibility with Prettier formatter
* Advanced linter supporting over 500 rules from ESLint, typescript-eslint, and more

**Installation and Usage**

* Install using `npm install --save-dev @biomejs/biome`
* Run format and lint without installing by executing `npx biome format` or `npx biome lint`

**Key Features:**

* Interactive editor support
* Formats and lints malformed code as you write it
* Advanced diagnostic tools to improve code quality
