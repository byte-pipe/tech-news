### dbt Core 2.0 Overview

#### Introduction to dbt Core v2.0

dbt-labs introduces **dbt-core**, the new foundation for data analytics and engineers to transform their data using the same practices that software engineers use.

#### Changes and Improvements in dbt Core v2.0

* **Faster**: Speed up parsing, compiling, and running projects with improved performance.
* **Stricter Language Specification**: Define correctness at parse time to ensure accuracy.
* **Scalable Artifacts**: Produce Parquet artifacts for efficient querying, joining, and analysis of database tables.
* **Easier Installation**: Single self-contained binary offering no Python runtime or dependency management required.
* **Modernized Local Documentation Experience**: Powered by new artifacts and scalable to large projects.

#### Supported Operating Systems and Architectures

* Compiling per operating system and architecture, with support for various platforms (x86-64, ARM, macOS, Linux, Windows).

### Getting Started with dbt Core v2.0

Analysts can transform their data using **select statements** in dbt projects. Models form a dataset that will be transformed into tables and views in the data warehouse.
