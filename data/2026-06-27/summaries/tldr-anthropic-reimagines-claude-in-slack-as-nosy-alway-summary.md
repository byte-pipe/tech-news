# Claude in Slack app Reimagined as a Noisy, Agentic AI Coworker

The current Claude in Slack app has been abandoned in favor of an "always-on agentic" alternative called Claude Tag. 

## Key Features:

- Allows Claude Tag to join organizational Slack instances and access domains, channels, tools, data, and codebases.
- Enables users to tag @Claude to delegate tasks and perform various actions based on environment context.
- Increases the model's proactive capabilities through its ability to write and learn new code.

## Advantages over the Previous App:

- Provides a more collaborative experience for coworkers by allowing them to interact with Claude in a more meaningful way.
- Enables users to receive more relevant information and updates without need for one-off advice from Claude.

## Key Changes and Benefits:

- Shared context between interactions allows colleagues to work together more effectively.
- Long-term contextual learning enables Claude Tag to remember the user's preferences and adapt its behavior accordingly.

## Potential Risks and Concerns:

- Anonymity concerns arise as users can request tasks without being identified or recognized by the Claude bot.
- Security and permissions issues may arise due to increased access to data and code bases.
