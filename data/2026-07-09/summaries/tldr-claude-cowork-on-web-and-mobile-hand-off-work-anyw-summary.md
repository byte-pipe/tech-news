# Claude Cowork is coming to mobile and web

## Overview
- Claude Cowork is expanding from laptop‑only to web and mobile platforms, allowing sessions and files to follow users across devices.  
- Beta rollout begins with Max users and will extend to additional plans over the coming weeks.  
- Primary use cases are everyday knowledge work (business operations, content creation) rather than pure software development, accounting for roughly half of all usage.

## What changes today
- **Work follows you** – start a task on a desktop, check progress on a phone, and retrieve finished output anywhere.  
- **Background execution** – tasks continue when the laptop is closed; scheduled jobs run without any device online (e.g., overnight client prep).  
- **Human‑in‑the‑loop decisions** – Claude prompts the user for decisions via their phone, and no output is shipped until the user reviews and approves it.  
- Desktop remains the hub for deep work and local file access; users without a desktop app can now use Cowork via web or mobile.  
- Chat and Cowork share a single home on web and desktop, and projects/artifacts are unified across surfaces.  

## Getting started
- **Web**: launch a Cowork session from the home screen at claude.ai.  
- **Mobile**: open Cowork from the sidebar in the Claude iOS or Android app.  
- **Desktop**: download the Claude desktop app for the full experience, including local file and browser integration.  
- Begin with an existing item (folder, thread, half‑finished deck) and describe the desired outcome.  
- Usage limits are doubled through August 5 to encourage larger tasks.
