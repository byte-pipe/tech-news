**Overview**
Lap is an open-source, local-first photo manager for macOS, Windows, and Linux that allows users to browse, organize, and manage large personal media libraries offline.

**Key Features**

* **Local-first**: Storing photos on the local disk, with no required cloud account or upload
* **No library lock-in**: Allows users to work directly with their existing folders instead of importing everything into a closed database
* **Private AI tools**: Search, similarity, smart tags, and face features run locally on the machine
* **Built for large collections**: Optimized for smooth browsing and organization across libraries with 100k+ files
* **Open source and free**: No subscription, no forced ecosystem, and code you can inspect

**Technical Details**

* **Package distributions**: Available for macOS, Windows 10/11, and Linux (x64 / ARM64)
* **Installation**: Supports Homebrew installation on macOS, and can be run from AppImage on Linux
