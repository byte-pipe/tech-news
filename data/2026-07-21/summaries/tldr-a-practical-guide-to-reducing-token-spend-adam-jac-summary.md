# A Practical Guide to Reducing Token Spend · Adam Jacob

## Reducing Token Spend for Complex Workloads
### What Went Wrong and How to Improve
A previous Sentry contributor spent over $10,000 on tokens for a week-long code review workload, highlighting the inefficiencies of current token-based workflows. The solution involves leveraging alternative approaches instead of relying solely on skills to reduce token spend.

## Key Findings
- **Token Usage Dropped by 8x**: Using an as-wasm workflow instead of individual skill usage reduced token usage by 8x.
- **Decreased Run Time by 2x**: Same-day token usage also saved development team 2x time due to reduced run times for complex code reviews.

## Recommended Approach
For many use cases, using as-wasm workflows can be a game-changer in reducing token spend and significantly decreasing run times for complex workloads.
