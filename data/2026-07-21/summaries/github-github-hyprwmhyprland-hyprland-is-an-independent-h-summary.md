# Hyprland: A Dynamic and Customizable Tiling Wayland Compositor

### Overview

Hyprland is a 100% independent, dynamic tiling Wayland compositor. It provides the latest Wayland features, is highly customizable, has advanced eyecandy options, and supports powerful plugins to enhance gaming performance.

### Key Features

* **Eyecandy Options**: Gradations of color, blur effects, animations, shadows, and more are available for customization.
* **Highly Customizable**: Users can create their own unique look with extensive control over various compositor settings.
* **100% Independent**: No dependency on wlroots, libweston, kWinn, mutter, or any other libraries can affect performance.
* **Custom Bezier Curves**: Exceptional animation quality is achieved through custom beziers for unparalleled visuals.
* **Powerful Plugin Support**: Extensive library of plugins ensures seamless integration with various applications and system services.
* **Built-in Plugin Manager**: Easily manage installed plugins to adjust settings without cluttering the interface.
* **Tearing Support**: Optimized performance results in smoother gaming experiences on multiple resolution levels.
