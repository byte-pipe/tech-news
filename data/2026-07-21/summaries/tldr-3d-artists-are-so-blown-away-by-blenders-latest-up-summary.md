# 3D artists are so blown away by Blender's latest update, it's hard to believe it's free software | Creative Bloq

Here is a concise and informative summary of the article:

** Blender 5.2 LTS Release: Key Features and Improvements**

Blender 5.2 LTS has been released, bringing several new features to make it an even better free 3D app for both 2D and 3D work.

* **Geometry Nodes**: A new physics system powered by XPBD (Extended Position-Based Dynamics) multiphysics solver allows simulations to run inside node trees, making them more efficient.
* **Thinner Wall Mode**: Physically accurate animation of thin walls in Principled BSDF.
* **Time-saving Texture Cache**: Dynamically generates and optimizes textures for scenes with large high-resolution image textures.
* **Advanced Collision and Forces**: Fleshed out self-collision and ready-made forces, including wind or turbulence.
* **Asset Libraries**: Allows artists to remotely host asset libraries on cloud-based services, reducing storage needs.
