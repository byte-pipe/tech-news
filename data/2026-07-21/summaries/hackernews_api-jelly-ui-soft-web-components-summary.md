## Jelly UI Overview
Jelly UI is a dependency-free library for creating soft, tactile product interfaces with Web Components.

### Key Features
* Real form controls with soft-body physics
* Dark mode support
* Right-to-left (RTL) support
* WCAG AA compliance

### Customizations
* Able to load 40 custom elements on the page
* Single script tag required for loading the library
* Automatic theme switching enabled in `auto` mode
