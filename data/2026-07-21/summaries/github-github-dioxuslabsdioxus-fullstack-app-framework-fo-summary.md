# GitHub - DioxusLabs/dioxus: Fullstack app framework for web, desktop, and mobile. · GitHub

### Overview of Dioxus Framework

#### Key Features:

* Zero-config setup
* Integrated hot-reloading
* Signals-based state management
* Server Functions for backend functionality
* Bundler with CLI deployment
* Built-in features: Ergonomic state management (combines React, Solid, and Svelte), Cross-platform app development in three lines of code

#### Key Capabilities:

* Multi-line of code (web, desktop, mobile, server)
* React, Solid, and Svelte based ecosystem
* Fullstack web framework with TypeScript support
* Rust hot-patching and asset hot-reloading
* WebSockets, SSE, Streaming, File Upload/Download, Server-Side-Rendering, Forms, Middleware, Hot-Reload capabilities

#### Features:

* Cross-platform app development for both clients and servers
* Built-in features include:
	+ TailwindCSS support
	+ Native code integration (Objective-C, JNI, Web-Sys)
	+ Customizable native code calling to axum backend
* First-party primits supported

### Dioxus Development Workflow

* Zero-config setup using `dx serve` command
* Hot reloading enabled through command-line interactive experience (`dx serve --hotpatch`)
* Built-in features for ergonomic state management, cross-platform app development, and multi-backend deployment
* Flexible customization options to integrate with custom front-end or backend codebases.
