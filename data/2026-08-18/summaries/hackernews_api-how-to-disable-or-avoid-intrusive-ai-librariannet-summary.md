# How to Disable or Avoid Intrusive AI – Summary

## Adobe Acrobat / Adobe Reader
- **Acrobat (Windows):** Menu → Preferences → Generative AI → uncheck the box, click **Save**.  
- **Acrobat (macOS):** View → Preferences → Generative AI → uncheck, click **Save**.  
- **Reader:** Choose **Disable new Acrobat Reader** from the top‑left menu, confirm, then restart.

## Android / Gemini
- **Uninstall:** If your phone’s OEM allows it, remove the Gemini app completely.  
- **Messages:** Tap your account picture → **Messages settings** → **Gemini in Messages** → toggle off.  
- **Other apps:** Profile icon → **Gemini Apps activity** → **Turn off** (or **Turn off and delete activity**). Then go to **Connected Apps** (or **Personal Intelligence**) and disable any apps you don’t want Gemini to access.  
- **Power button:** Settings → System → Gestures → Press & Hold Power Button → disable. If not found, search “Power key” in Settings.

## Amazon
- Install a browser extension (Chrome or Firefox) to hide the **“Alexa for Shopping”** slider.

## Apple Intelligence & Siri (iPhone 16+, newer Macs & iPads)
- Settings (iPhone/iPad) or System Settings (Mac) → **Apple Intelligence & Siri** → turn off **Apple Intelligence** and confirm.  
- To stop apps from learning:  
  - **Mac:** System Settings → Apple Intelligence & Siri → About Siri, Dictation & Privacy → disable per‑app learning.  
  - **iOS:** Settings → Apple Intelligence & Siri → Apps → turn off **Learn from this App**.

## Browser‑Embedded AI
- **Alternative browsers:** Zen, Helium, LibreWolf, Waterfox (Firefox‑ or Chromium‑based).  
- **Chrome (AI Nano):** `chrome://flags` → search “GLIC” and “Gemini” → set all to **Disabled**.  
- **Edge:** `edge://flags` → search “AI” or “Copilot”. Then Settings → Appearance → **Copilot and sidebar** → turn off sidebar, top‑site personalization, and notifications. Disable Copilot button in toolbar and language‑specific Copilot writing.  
- **Firefox (v148+):** Settings → **AI Controls** → enable **Block AI Enhancements** (or select granular options). Optional extension to strip AI from Google search results.  
- **DuckDuckGo:** Use the no‑AI version at `https://noai.duckduckgo.com/` or switch default search to that site; the DDG browser also offers a built‑in no‑AI mode.

## Google Workspace (Gmail, Docs, etc.)
- Gmail web: Settings → **See all settings** → General → **Google Workspace smart features** → **Manage Workspace smart feature settings** → toggle off **Smart features in Google Workspace** and **Smart features in other Google products**; also uncheck **Turn on smart features in Gmail, Chat, and Meet**.  
- Gmail Android: Settings (hamburger) → **Account name** → disable workspace smart features.

## Slack
- Workspace owners/admins can disable AI features via Slack’s admin settings (see Slack help page for “Managing AI features”).

## WhatsApp
- **Suggested replies & AI stickers:** Settings → Chats → **Suggestions & smart replies** → toggle off.  
- **AI message summaries:** Settings → Notifications → **AI message summaries** (or Settings → Chat → Private Processing → Private Processing Features, depending on OS).

## Windows 11 / Copilot
- **Uninstall Copilot:** Right‑click Copilot in Start menu → **Uninstall**, or go to Settings → Apps and remove it.  
- If Copilot is baked into the OS, disable via Settings → Personalization → Taskbar → turn off **Copilot**.  
- **File Explorer AI:** Settings → Privacy & Security → **Turn off AI features**.  
- **Notepad AI:** Open Notepad settings → locate **AI features** (or sparkly icon near Writing Tools) → toggle off.  
- **Office 365 / Outlook:** Each app has its own **Enable Copilot** checkbox; turn it off per app, or adjust privacy settings to block Copilot.  
- **System‑wide text & image generation** (affects Notepad, Photos, Snipping Tool, Xbox): disable in Settings → **Privacy & Security** → **AI generation**.  
- For deeper removal, tools like **O&O ShutUp10** or **Win11DeBloat** can be used (advanced users only).
