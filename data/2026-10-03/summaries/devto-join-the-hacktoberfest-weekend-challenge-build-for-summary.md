# Hacktoberfest 2026 – Weekend Challenge: Build for a Friend  

## Overview  
- First of five weekend‑sized DEV challenges, running from Oct 2 – Oct 5, 2026.  
- Focus: create a new project that uses open‑source AI at its core and solves a real problem for a specific friend or loved one.  
- No pull‑request quota; the competition is about building and writing about the project on DEV.  

## Prompt: Build for a Friend  
- Choose one real person and develop a solution that matters to them (e.g., allergy‑aware meal planner, language‑practice partner, voice‑memo‑to‑recipe tool).  
- The solution must rely on open‑source AI components (open‑weight model, open‑source agent framework, local inference, etc.).  
- In the DEV post, explain why open innovation was essential (offline operation, data privacy, model flexibility, cost‑free runtime, etc.).  
- Bonus: actually deliver the tool to the friend and share their feedback.  

## Prize Categories  
- **Overall winner** plus one winner in each of 16 partner categories (total 17 winners).  
- Featured partner categories include: Render, TabPFN, Tinker, Arduino, DigitalOcean, Gemma.  
- Additional partner categories: Backboard, ElevenLabs, Entire, GitHub Copilot, Mastra, MongoDB Atlas, Sentry Agent Tracing, SerpApi, Temporal, Tiger Data.  
- Entries may compete in any category they genuinely use; a single project can win only once.  
- Partner categories have fewer submissions, increasing odds of winning.  
- Free credits and promo codes are available from several partners (Tinker, Render, Backboard, ElevenLabs).  

## Judging Criteria  
- **Writing Quality** (most weight): clarity, engagement, explanation of the build, target user, and open‑innovation benefits.  
- Relevance to the prompt and open‑source AI core.  
- Creativity of the idea or approach.  
- Technical execution and functionality.  
- Optional: meaningful use of a partner technology for partner‑category entries.  

## Prizes  
- Overall winner: $250 USD, DEV++ membership, exclusive DEV badge.  
- Six featured category winners: $200 USD each + exclusive badge.  
- Ten partner category winners: $100 USD each + exclusive badge.  
- All valid submissions receive a completion badge.  

## How to Participate  
1. Publish a DEV post using the provided submission template.  
2. Describe the project, the intended friend, demo the solution, and discuss open‑innovation impact.  
3. Review judging criteria, rules, and FAQ before submitting.
