# Announcing AWS Well‑Architected Agent (preview) – Summary

## Overview
- Public preview of an AI‑powered service that analyzes AWS environments and delivers contextual recommendations for cost, security, performance, and resilience.  
- Evaluates infrastructure like an experienced cloud architect, correlating utilization metrics, resource configurations, and application topology across 65+ AWS services.  
- Generates goal‑aligned recommendations with ready‑to‑implement fixes, avoiding manual audits and generic checklists.

## Core Features
- **Goal‑aligned intelligence** – Recommendations are prioritized by impact and effort against declared business objectives.  
- **Three‑level recommendations** –  
  1. Individual resource findings with specific dollar impact and step‑by‑step remediation.  
  2. Consolidated findings across multiple resources scoped to an application.  
  3. Broad architectural patterns with Infrastructure as Code (IaC) changes needed to meet Well‑Architected best practices.  
- **Optionality in remediation** – Choose console walkthroughs, updated IaC templates, or AWS CLI commands for implementation.

## Getting Started
- Create an agent profile in the AWS Well‑Architected console: select AWS accounts or regions, optimization pillars, and set goals (cost, performance, resilience, security).  
- Provision a customer‑managed IAM role that grants the agent read‑only access to resource configurations, utilization metrics, and topology.  
- Recommendations are generated within 24 hours of profile creation.  
- Optional pre‑deployment review: upload a Terraform, CloudFormation, or CDK IaC project, select a Well‑Architected lens, and run an architecture review.  
- Add application context (accounts, regions, services, tags) to improve relevance of recommendations.

## Reviewing & Acting on Recommendations
- View a prioritized list of recommendations ranked against declared goals, with automation‑ready remediation details.  
- Each recommendation includes insights on why it is suggested, impacts, trade‑offs, and affected resources.  
- Remediation paths:  
  - Console step‑by‑step instructions.  
  - Updated IaC template with exact code changes.  
  - CLI commands for direct execution.  
- Updated IaC code can be copied directly into existing codebases.

## Integration & Automation
- API access enables integration of recommendations into existing development and operations workflows.  
- Supports AWS MCP Server and plugins for preferred AI coding tools.  

## Important Considerations
- Automation delivers precise IaC changes; recommendations are refreshed periodically.  
- Generated by generative AI and may contain errors or incomplete information; customers must evaluate recommendations in their specific context and apply appropriate oversight per AWS Responsible AI practices.  
- The existing AWS Well‑Architected Tool remains available for manual assessments using user‑defined lenses.

## Availability & Access
- Preview is available in US East (N. Virginia), US East (Ohio), and US West (Oregon); workloads from any AWS commercial region can be onboarded.  
- Delivered by AWS Support and requires an AWS Support plan.  
- Users are encouraged to try the service in the AWS Well‑Architected console and provide feedback through standard AWS Support channels.
