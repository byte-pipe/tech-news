Apple has just released a patch update to macOS Tahoe to bring it to version 26.5.1. This “addresses an issue for enterprise users where Mac computers with an M5 chip could unexpectedly shut down using certain content filtering network extensions.”

There are no security release notes, as Apple states there are no published CVE entries for this update.

The update for Apple silicon Macs is around 2.14 GB in size.

There are no firmware updates, with mBoot for Apple silicon Macs remaining at 18000.120.36. There are no updates to bundled apps, with Safari remaining at version 26.5 (21624.2.5.11.4). Neither are there any significant changes to the contents of /System/Library.

The Darwin kernel version remains at 25.5.0, with XNU of 12377.121.6-2. The build number advances slightly, from 25F71 in 26.5 to 25F80. Paired Recovery should also be updated to 26.5.1, but Fallback Recovery is likely to remain at 26.3 or thereabouts.

This patch update appears to fix a single problem affecting M5 Macs being used in an enterprise setting. For users of other models, you needn’t rush to install it.
