# OpenAI frontier models and Codex are now available on AWS

## Overview
- OpenAI’s frontier models and Codex are now generally available on Amazon Web Services (AWS).  
- The integration aims to reduce enterprise barriers to AI adoption by leveraging existing AWS security, compliance, procurement, billing, and governance workflows.  
- Enterprises can move more quickly from evaluation to production using familiar AWS tools.

## How the capabilities are offered
- **OpenAI models on Amazon Bedrock** – Enables building AI applications with AWS‑native security and governance controls.  
- **Codex on Amazon Bedrock** – Provides OpenAI’s software‑engineering agent (used by >5 million weekly users) for code writing, review, debugging, and modernization within existing AWS development environments.  
- Both offerings are available in Commercial and GovCloud regions.

## Customer adoption and examples

- **Autodesk**: Evaluating how frontier AI and Codex can speed up design workflows, improve precision, and support better decision‑making on secure, scalable AWS infrastructure.  

These testimonials illustrate how organizations can leverage the new AWS path to reduce procurement, security review, and production‑readiness friction.

## Future roadmap and cyber‑security focus
