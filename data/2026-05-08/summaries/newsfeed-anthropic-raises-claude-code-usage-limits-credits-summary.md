# Anthropic raises Claude Code usage limits, credits new deal with SpaceX

## Deal overview
- At the “Code with Claude” developer conference, Anthropic announced a partnership with SpaceX to use the full compute capacity of SpaceX’s Memphis data center.  
- The agreement is intended to raise usage limits for Anthropic’s Pro and Max plan subscribers.

## Usage limit changes
- Claude Code’s five‑hour window limits for Pro and Max users were doubled.  
- The peak‑hours limit reduction for those plans was removed.  
- API limits for the Opus model were increased, as detailed in Anthropic’s blog post.

## Compute capacity details
- Anthropic claims the deal provides access to more than 300 MW of new compute power.  
- SpaceX highlighted the “Colossus 1” supercomputer, featuring over 220,000 NVIDIA GPUs, including H100, H200, and upcoming GB200 accelerators.  
- Anthropic expressed interest in collaborating on “multiple gigawatts” of orbital compute capacity to address terrestrial power, land, and cooling constraints.

## Context and reactions
- The partnership is notable because Elon Musk previously criticized Anthropic, calling it hostile to Western civilization.  
- Musk later tweeted that after meeting Anthropic’s senior team, he was impressed and detected no “evil” in their work.

## Demand and compute constraints
- Anthropic has experienced a surge in demand for Claude Code and related products, driven by:
  - Users shifting from OpenAI after controversies over military contracts.  
  - Growing adoption of Claude Code in professional software development.  
  - A move from single‑agent chat tasks to more complex multi‑agent workflows.  
- To manage demand outpacing available compute, Anthropic previously introduced peak‑hour limits and briefly tested removing Claude Code from the $20/month Pro plan, prompting frustration among developers on forums such as Hacker News and Reddit.

## Recent partnerships
- In the prior month, Anthropic signed large agreements with Microsoft, Google, Amazon, Nvidia, and others to expand its compute infrastructure.  
- The company credits these deals, together with the SpaceX agreement, for enabling the recent limit increases, though some benefits will materialize over time.
