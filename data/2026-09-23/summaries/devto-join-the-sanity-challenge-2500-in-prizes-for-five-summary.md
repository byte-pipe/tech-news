# Join the Sanity Challenge: $2,500 in prizes for FIVE winners!

## Overview
- Challenge runs from September 18 to October 4.  
- Participants can either build an AI agent that queries structured content or “vibe‑code” an app with Sanity as the backend.  
- Total prize pool is $2,500: three winners for Path 1 and two winners for Path 2, each receiving $500, a DEV++ membership, and an exclusive DEV badge.  
- Every valid submission earns a completion badge on the participant’s DEV profile.

## Paths & Submission Requirements
### Path 1 – Ship an agent that queries real content
- Use any agent framework and point it at a Sanity Context MCP endpoint backed by a Knowledge Base.  
- The agent must rely on structured content; simple keyword search should not suffice.  
- Provide a submission using the Path 1 template and include your Sanity project ID or a link to a public dataset URL.

### Path 2 – Vibe‑code something strange
- Build a front‑end app (e.g., Next.js, Astro) with Sanity behind it.  
- Judges look for depth of Sanity feature usage, custom UI work, and workflow integration.  
- Bonus points for using the App SDK or modeling content workflows as data.  
- Provide a submission using the Path 2 template and include your Sanity project ID or a public dataset URL.

## Judging Criteria
- **Path 1:** meaningful use of Sanity Context and structured content, technical implementation and code quality, Knowledge Base integration, usability.  
- **Path 2:** honesty and quality of the build‑process write‑up, functionality of the finished app, thoughtfulness of the schema, creativity and originality.

## How to Participate
- Publish a DEV post using the appropriate template and tag it with `#sanitychallenge`.  
- Create separate posts for each path if you submit to both.  
- If the app requires login, include testing credentials or clear testing instructions.  
- Optional: embed an agent session transcript (Claude Code, Gemini CLI, etc.) instead of screenshots for clearer demonstration.

## Resources & Getting Started
- **Sanity Context:** required reading for Path 1.  
- **Day One with Sanity:** guided course for newcomers.  
- Documentation on schemas, GROQ, and Studio.  
- Guides on Knowledge Bases, App SDK, and workflows.  
- Framework quickstarts: Next.js, Astro, Nuxt, React Router.  
- Sanity Discord (MCP server channel) for community support.

## Important Dates
- **September 18:** Challenge begins.  
- **October 4, 11:59 PM PDT:** Submission deadline.  
- **October 22:** Winners announced.
