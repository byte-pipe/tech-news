# XERJ Overview

XERJ (X-Elastic Search for Retargeting for Intelligence) is a community-trusted local AI search tool that enables efficient and effective indexing of code and technical data.

## Key Features

- **Automatic Code Indexing**: XERJ indexes every folder automatically, reducing token waste and increasing search efficiency.
- **Reference Coding**: Agents are trained to point to the closest available source of knowledge, reducing the need for manual source code searches.
- **Memory Efficiency**: XERJ reuses solutions to previous problems, streamlining the development process.

## Installation and Usage

### Installing XERJ

- Clone the repository via `git clone https://xerj.org/`.
- Run `git install` to install the tool.
- Initialize XERJ by running `xerj init`, then run `xerj autoindex`.

### Searching XERJ

- Run the command `xerj search` to search for and index new sources of data.

### Advanced Features

- ** WAL Segment Rotation**: XERJ rotates the WAL (Write-Ahead Log) segment for improved data persistence.
- **Security**: Use the `--insecure` flag to disable all security features, allowing the tool to be run with minimal configuration and by a single user.
