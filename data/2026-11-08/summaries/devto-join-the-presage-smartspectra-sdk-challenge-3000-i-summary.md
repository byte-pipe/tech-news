# Join the Presage SmartSpectra SDK Challenge – $3,000 in Prizes Across 10 Winners

## Overview
- Challenge runs from **Nov 4 to Nov 22**.
- Build an app using the Presage SmartSpectra SDK that reacts to real‑time human signals captured via camera (pulse, breathing rate, HRV, expressions, etc.).
- Total prize pool: **$3,000** for ten winners (four overall, six category winners).

## Prompt
- **Best Overall Human‑Sensing Experience**: create a functional experience that meaningfully responds to live camera‑based human signals.

## Prize Categories
- **Most Creative or Delightful Use** – original, playful, or unexpected applications.
- **Best Thoughtful Real‑World Use** – clear real‑world need, strong usability, consent, and responsible data handling.
- Submissions can be entered for a category and still qualify for an overall win; each participant may submit only one entry.

## Submission Requirements 📌
- Individual participants only (18+); no team entries.
- Must integrate the SmartSpectra SDK and use at least one live signal.
- Required deliverables:
  * DEV post using the provided template (include `#presagechallenge` tag).
  * Public code repository with clear setup instructions.
  * Demo video (public hosting optional).
  * Consent and data‑handling statement (disclose storage, sharing, retention, deletion, SDK telemetry, optional AI services).
- Provide testing credentials if the app requires login.
- Prohibited: medical diagnosis/treatment claims, covert or non‑consensual monitoring.

## Judging Criteria
- Effective use of the underlying technology.
- Usability and overall user experience.
- Originality and creativity.

## Prizes 🏆
- **Overall Winners (4)**: $300 USD + DEV++ Membership + exclusive DEV badge.
- **Most Creative or Delightful Use (3)**: $300 USD + DEV++ Membership + exclusive DEV badge.
- **Best Thoughtful Real‑World Use (3)**: $300 USD + DEV++ Membership + exclusive DEV badge.
- All valid submissions receive a completion badge on their DEV profile.

## How to Participate
- Publish a DEV post with the submission template and required tag.
- Include testing credentials or clear instructions for judges.
- Optional: embed an agent session transcript (make it public before publishing).

## Getting Started with SmartSpectra 🚀
- Learn about Presage and read the SmartSpectra documentation.
- Use the Desktop Starting Point (Node.js/Electron) to bootstrap.
- Register for an API key.
- Review telemetry and privacy guidelines for the consent section.
- Access the SDK on GitHub.
- Find additional resources on MLH and the Presage Discord (for credit limits or questions).
