# Join the Presage SmartSpectra SDK Challenge

## Overview
- The Presage SmartSpectra SDK Challenge runs from November 4 to November 22.  
- Build an experience that reacts to real‑time human signals captured via camera (pulse, breathing rate, HRV, expressions).  
- Total prize pool: $3,000 across ten winners.

## Prompt
- **Best Overall Human‑Sensing Experience**: Create a functional app using the SmartSpectra SDK that meaningfully responds to live camera‑derived signals.

## Prize Categories
- **Most Creative or Delightful Use** – rewarding original, playful, or unexpected applications.  
- **Best Thoughtful Real‑World Use** – rewarding solutions that address a clear real‑world need with strong usability, consent, and responsible data handling.  
- Submissions can compete for an overall win and/or one or both prize categories, but each participant may submit only one entry and each entry can win only once.

## Submission Requirements 📌
- Individual participants only; must be 18 +; no team entries.  
- Must integrate the SmartSpectra SDK and use at least one live Presage signal.  
- Required deliverables: DEV post using the provided template, public code repository, setup instructions, and demo video (public hosting optional).  
- Include a consent and data‑handling section detailing camera consent, storage, sharing, retention, deletion, SDK telemetry, and any optional AI services.  
- Disallowed content: diagnosis/treatment claims, medical decision‑making, covert or non‑consensual monitoring.  

## Judging Criteria
- Effective use of the underlying technology.  
- Usability and overall user experience.  
- Originality and creativity.

## Prizes 🏆
- **Overall Winners (4)**: $300 USD, DEV++ Membership, exclusive DEV badge.  
- **Most Creative or Delightful Use (3)**: $300 USD, DEV++ Membership, exclusive DEV badge.  
- **Best Thoughtful Real‑World Use (3)**: $300 USD, DEV++ Membership, exclusive DEV badge.  
- All valid submissions receive a completion badge on their DEV profile.

## How to Participate
- Publish a DEV post using the submission template and tag it with `#presagechallenge`.  
- Provide testing credentials or clear instructions if the app requires login.  
- Optional: embed an agent session transcript to show development process (make it public and scrub sensitive data).  
- Review the judging criteria, rules, guidelines, and FAQ before submitting.

## Getting Started with SmartSpectra 🚀
- Learn about Presage and the SmartSpectra SDK.  
- Use the Desktop Starting Point (Node.js & Electron) for quick setup.  
- Register for an API key as a developer.  
- Read the Telemetry and Privacy guide for the consent section.  
- Access the SDK repository on GitHub.  
- Additional resources: MLH guides, Presage Discord for support.  
- Note: the challenge runs on Presage’s free trial; contact Discord if you hit credit limits.

## Important Dates
- **November 4** – Challenge begins.  
- **November 22, 11:59 PM PST** – Submission deadline.  
- **December 10** – Winners announced.
