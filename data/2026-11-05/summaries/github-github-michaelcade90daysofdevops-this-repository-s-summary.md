# Summary of the 90DaysOfDevOps Repository

## Overview
- The repository documents the author’s 90‑day learning journey into DevOps, beginning 1 January 2022 and ending 31 March 2022.  
- Initially a “learning in public” project, it has evolved into a structured learning map covering DevOps foundations, processes, and tooling.  

## Main Content Areas
- **DevOps** – Written by the author, later translated, corrected, and enhanced by the community; ~110 k words.  
- **DevSecOps** – Extends the DevOps material with security focus and additional topics contributed by community subject‑matter experts.  
- **Community Edition** – 91 community‑hosted sessions available on YouTube, featuring diverse media formats to enrich the resource collection.
