## What is OpenToonz?

OpenToonz is a 2D animation software published byDWANGO. It is based onToonz Studio
Ghibli Version, originally developed in Italy byDigital Video, Inc., and customized byStudio Ghibliover many years of production.

## Program Requirements

Please refer to the OpenToonz site athttps://opentoonz.github.io/e/index.html.

## Installation

Please download and install OpenToonz from the latest installer athttps://opentoonz.github.io/e/index.html.

Older versions and unstable nightly builds are also available athttps://github.com/opentoonz/opentoonz/releases.
