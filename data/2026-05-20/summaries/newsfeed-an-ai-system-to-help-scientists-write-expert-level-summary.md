# An AI system to help scientists write expert-level empirical software

## Overview
- Scientific discovery is often slowed by the manual creation of software needed for computational experiments.  
- The paper introduces Empirical Research Assistance (ERA), an AI system that generates expert‑level scientific software with the goal of maximizing a defined quality metric.

## Core Technology
- ERA combines a Large Language Model (LLM) with Tree Search (TS) to systematically explore and improve software solutions.  
- The system evaluates candidate programs against the quality metric and intelligently navigates the large space of possible implementations.  
- It incorporates complex research ideas from external sources to achieve expert‑level performance.

## Performance Highlights
- **Bioinformatics**: Discovered 40 novel methods for single‑cell data analysis, each outperforming the top human‑developed methods on a public leaderboard.  
- **Epidemiology**: Generated 14 models for forecasting COVID‑19 hospitalizations that outperformed the CDC ensemble and all other individual models.  
- **Additional Domains**: Produced expert‑level software for geospatial analysis, neural activity prediction in zebrafish, numerical integration of integrals, and introduced a novel rule‑based construction for time‑series forecasting.

## Significance
- Demonstrates that a tree‑search‑guided LLM can reliably create high‑quality scientific software across diverse research areas.  
- Represents a substantial step toward accelerating scientific progress by reducing the bottleneck associated with manual software development.
