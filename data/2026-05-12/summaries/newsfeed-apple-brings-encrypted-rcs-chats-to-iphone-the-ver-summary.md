# Apple brings encrypted RCS chats to iPhone

## Overview
- Apple introduced end‑to‑end encrypted RCS messaging for iOS in the iOS 26.5 beta, allowing secure chats with Android users via the Messages app.  
- The feature shows a lock icon and an “Encrypted” label when active, and is enabled by default for new and existing RCS conversations on supported carriers.  

## Requirements
- iOS 26.5 (beta) on iPhone.  
- Android participants must run the latest version of Google Messages.  
- Both parties need carriers that support encrypted RCS.  

## Additional iOS 26.5 Changes
- New wallpapers added to the system.  
- Maps now displays local advertisements based on approximate location, search terms, or map view; ad data is not linked to the Apple account.  

## Related OS Releases
- Apple simultaneously released version 26.5 updates for iPadOS, macOS Tahoe, watchOS, tvOS, and visionOS.
