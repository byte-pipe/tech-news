# Nebula Sans

# Nebula Sans Summary

## Overview
- A modern humanist sans‑serif created as the brand typeface for Nebula, an indie streaming service.  
- Designed for legibility across digital and print media.  
- Based on Source Sans by Paul D. Hunt and positioned as a drop‑in alternative to Whitney SSm.  
- Released under the SIL Open Font License, free for anyone to use.

## Styles and Weights
- Six primary weights: Light, Book, Medium, Semibold, Bold, Black.  
- Each weight includes a matching italic style.  
- Sample taglines illustrate the personality of each style (e.g., “Don’t use seven words when four will do” for Medium, “Powered by humans” for Black).

## Intended Use Cases
- Interfaces, print, and any graphical, digital, physical, or conceptual typographic needs.  
- Suitable for branding, UI design, video player timestamps, and more.

## Reasons for Creation
- **Personalization:** Ability to tailor the font to Nebula’s visual identity.  
- **Features:** Integration of advanced typographic options specific to the service’s requirements.  
- **Sustainability:** Avoiding escalating costs of commercial font licenses as the platform grows.

## Design Foundations
- Source Sans served as the base because it shares core traits with Whitney SSm, both bridging American gothic and European humanist styles.  
- Adjustments focused on metric alignment so Nebula Sans matches the spacing and proportions of Whitney SSm while retaining Source Sans’s narrower default shape.

## Comparison to Whitney SSm
- **Metrics:** Nebula Sans adapts Source Sans metrics to mirror Whitney SSm’s width and height.  
- **Punctuation:** Curly glyphs from Source Sans replace the straighter punctuation of Whitney SSm.  
- **Stylistic Alternates:** Includes the same alternates as Source Sans, with defaults aligned to Whitney SSm (single‑storey “a”, open “g”, tailed “l”).  
- **Asterisk:** Redesigned with a star‑like form to reflect the brand’s motif.  
- **Tabular Figures:** Provides monospaced numerals, enabling stable timestamps and aligned numeric data—something Whitney SSm lacks.

## Typographic Details
- **Punctuation:** Curly quotes and commas for a softer visual tone.  
- **Stylistic Alternates:** Accessible via OpenType feature tags (`'ss01'` for single‑storey a, `'ss02'` for open g, `'ss03'` for tailed l).  
- **Asterisk:** Custom star‑shaped glyph used in branding.  
- **Tabular Figures:** Default lining figures support consistent column alignment in tables and UI elements.
