# Apple’s new desktop computers are designed specifically for local AI development

## Overview
- Apple refreshed the Mac mini and Mac Studio, introducing the M6 and M5 Ultra chips.
- The updates focus on enhancing local AI inference and development rather than adding consumer‑facing features.

## Key hardware changes
- **M6 (Mac mini)**
  - First 2 nm Apple silicon.
  - 12‑core CPU: 2 “super” cores, 4 performance cores, 6 efficiency cores.
  - 12‑core GPU, up to 160 GB/s unified memory bandwidth.
  - Memory capped at 32 GB.
- **M5 Ultra (Mac Studio)**
  - Combines two M5 Max dies.
  - 36 CPU cores (12 super, 24 performance) and 80 GPU cores.
  - Up to 512 GB unified memory, 1.2 TB/s memory bandwidth.
- Both models include Apple’s N1 chip (Wi‑Fi 7, Bluetooth 6), up to 15 GB/s storage, 2.5 Gb Ethernet (optional 10 Gb).

## AI‑focused capabilities
- macOS 26.2 introduced Thunderbolt 5 and MLX, enabling low‑latency, daisy‑chained inference across multiple Macs.
- Developers use Mac mini/Studio clusters to run large language models larger than a single consumer device can handle, offering an alternative to high‑end Nvidia GPU rigs.
- Larger memory and bandwidth of the M5 Ultra target demanding local inference workloads and other GPU‑intensive tasks like gaming and 3D rendering.

## Market positioning & pricing
- Mac mini with M6 starts at **$899** (16 GB RAM).
- Mac mini with M5 Pro starts at **$1,699**.
- Mac Studio with M5 Max starts at **$2,499**; M5 Ultra configurations start at **$5,499**.
- Pre‑orders begin today; shipping starts September 22 (512 GB Studio config later in October).

## Software context
- Devices will ship with macOS 27 “Golden Gate,” expected to be released to all Macs later in the year.
- Local AI models (e.g., Qwen, DeepSeek) can run on these machines, reducing reliance on costly cloud APIs.
