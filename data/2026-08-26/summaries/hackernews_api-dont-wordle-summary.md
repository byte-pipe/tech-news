# Don't Wordle

## Overview
- Free daily word game inspired by Wordle.
- Objective is to avoid guessing the hidden word within six attempts.

## Gameplay
- Six guesses are allowed each day.
- Color clues after each guess:
  - Green: correct letter in correct position.
  - Yellow: correct letter in wrong position.
  - Gray: letter not in the word.
- Players aim to keep as many valid words possible without revealing the answer.
- Limited undos let you retract a guess if you get too close.

## Features
- Daily single puzzle.
- Statistics tracking.
- Ability to share results with friends.
