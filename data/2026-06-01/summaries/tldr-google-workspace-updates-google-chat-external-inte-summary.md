# Google Chat external interoperability with Microsoft Teams via NextPlane OpenHub is now available

## Overview
- NextPlane OpenHub enables direct communication between Google Chat users and external Microsoft Teams tenants.
- Supports cross‑platform collaboration across organizational boundaries without requiring all parties to use the same tool.

## Key Features
- Presence, 1:1 chat, group chat, Channels, Spaces, file sharing, and meeting/call initiation.
- A single Google Workspace environment can connect to multiple external Teams tenants.
- Enterprise‑grade governance: dedicated single‑tenant service, optional deployment in a customer‑owned GCP project, customer‑managed identities, and no proxy or fake accounts.

## Administration & Management
- Configured through existing Google Admin console and Microsoft Teams admin center; no separate OpenHub console.
- Requires administrator consent on both sides and registration of OpenHub as an enterprise application.
- No end‑user settings needed.

## Use Cases
- Collaborate with customers, partners, and suppliers using Teams.
- Enable cross‑tenant collaboration from one Google Workspace environment.
- Support multi‑company projects, joint ventures, or extended partner workflows.
- Provide interoperability when domain validation limits internal solutions.

## Rollout
- Available now for both Rapid Release and Scheduled Release domains.

## Availability
- Business plans: Business Starter, Standard, Plus.
- Enterprise plans: Enterprise Starter, Standard, Plus.
- Requires separate NextPlane licensing.
