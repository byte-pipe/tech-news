# Eye of Sauron: Long-Range Hidden Spy Camera Detection and Positioning with Inbuilt Memory EM Radiation | USENIX

## Eye of Sauron: Detecting and Locating Hidden Spy Cameras

**System Overview**

The Eye of Sauron system is designed to detect and locate hidden spy cameras using inbuilt memory EM radiation. The system consists of two main components: a video capture device and a receiver station.

**Key Components**

* **Video Capture Device**: This device stores the captured video images in its read-write memory.
* **Memory Clock**: This device drives a variable number of switching voltage regulator activities based on workloads, causing fluctuating currents injected into memory units.
* **EM Radiation**: The system emits electromagnetic radiation (EMR) signals at the clock frequency due to the operations of the memory clock.

**Detection Mechanism**

1. **Intentional Scene Changes**: To stimulate the visual scene change and cause the EMR patterns to surge, the user intentionally applies scene changes to the system.
2. **EMR Sensing**: The system senses the surge of EMRs caused by the video encoding process by monitoring the changes in the memory workload.
3. **Location Determination**: The system accurately determines the location of the hidden spy camera based on the EMR patterns and the changes in the memory workload.

**Advantages**

* **High Accuracy**: The system can detect spy cameras with an accuracy of 100% after only 4 stimuli.
* **Long Detection Range**: The system can detect spy cameras from distances exceeding 20 meters.
* **Resistance to Blockages**: The system can accurately locate spy cameras even in the presence of blockages.

**Implementation**

The system is implemented in a proof-of-concept prototype and includes the following steps:

1. Design Techniques: Intentionally stimulate scene changes to cause the EMR patterns to surge.
2. Memory EMR Sensing: Monitor the changes in the memory workload to detect the surge of EMRs.
3. Location Determination: Accurately determine the location of the hidden spy camera based on the EMR patterns and the changes in the memory workload.

**Experimental Results**

Experiments with 50 camera products demonstrate the system's effectiveness, with:

* 100% accuracy after 4 stimuli
* Detection range exceeding 20 meters
* All spy cameras accurately located

**Conclusion**

The Eye of Sauron system is a novel approach for detecting and locating hidden spy cameras. Its high accuracy, long detection range, and resistance to blockages make it a viable solution for surveillance and security applications.
