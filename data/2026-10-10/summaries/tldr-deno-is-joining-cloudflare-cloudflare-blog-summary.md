# Deno is joining Cloudflare | Cloudflare Blog

**Deno to Join Cloudflare: Simplifying Self-Hosted Workers and Durable Objects**

Ryan Dahl and Kenton Varda are joining Deno, the open-source runtime, to merge its Worker and CellDurableObject models. This development further simplifies developing self-hosted projects like Workers and Durable Objects, enabling developers to use similar primitives across multiple locations.

**What's Happening**

The Deno team's efforts aim to:

* Remove complexity and provide a more straightforward programming model by simplifying asynchronous programming
* Use a powerful abstraction like Durable Objects, which provide a distributed singleton for managing data and WebSocket connections

**The Background Story**

Deno's journey began with introducing Node.js in a Berlin warehouse, focusing on Node.js 500-line JavaScript IRC server and live audience participation. Node.js already included asynchronous I/O capabilities but was restrictive for complex systems. The Deno team was born to find ways to simplify and make more powerful abstractions available.

**Real-World Implications**

Key features of this updated approach include:

* Simplifying project development by using a unified programming model
* Removing capabilities for data storage and computation, making development more efficient
* Allowing for scalability and performance through distributed architectures

**Parting Thoughts**

The Deno team's journey toward simplifying self-hosted Workers and Durable Objects through Cloudflare's support is a significant step forward. This integration will make it easier for developers to build robust, scalable applications across multiple locations, enabling more precise control over their projects.
