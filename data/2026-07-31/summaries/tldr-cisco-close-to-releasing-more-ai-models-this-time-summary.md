# Cisco close to releasing more AI models, this time for deep networking ops

## Main announcement
- Cisco has created its own deep‑networking AI model that “understands routing and switching configs” and can solve network problems better than frontier models.  
- The model will be published on Hugging Face shortly, together with the Antares security models.  
- The model powers the Cloud Control agentic‑ops platform, letting administrators query infrastructure, diagnose issues (e.g., a flaky connection) and receive action recommendations such as a reboot, with an explanation of the blast radius.

## Cloud Control details
- Cloud Control is Cisco’s answer to console sprawl, providing a single AI‑driven interface to its entire product portfolio.  
- Agents run under Cloud Control, pulling and analysing data from any deployed Cisco product to diagnose problems quickly.  
- US customers will get access by the end of August 2026; Europe and APAC follow in the subsequent months.  
- Pricing is not finalised: subscriptions will include a baseline token allowance, with extra tokens billed separately.  
- Cisco will also offer the networking models for on‑premises deployment (including on UCS servers) for customers who prefer to avoid token‑based pricing.

## Release timeline & constraints
- US rollout targeted for end‑August 2026.  
- Delays for Europe and APAC are due to infrastructure build‑out and regulatory requirements around access to customer systems and data governance.  
- Cloud Control is not intended to replace existing product‑specific consoles soon, as many customers have built processes and trained staff around them.

## Additional context mentioned
- Cisco is expanding SONiC availability to all customers, not just hyperscalers.  
- Recent AI initiatives include using AI to write security incident reports and uncovering bugs in Secure Workload.  
- Gartner predicts early AI‑management tools will initially add some bloat to organizations’ fleets of management tools.

## Token and on‑prem considerations
- AI queries consume tokens; Cisco will allocate a certain number with each subscription and charge for over‑usage.  
- The on‑premise option lets customers run models locally, avoiding token economics and giving tighter control over data.

## Regulatory and security notes
- Cloud Control requires access to customers’ systems, raising data‑privacy and governance concerns that vary by region.  
- Cisco emphasizes compliance with local security and governance laws as part of the rollout plan.
