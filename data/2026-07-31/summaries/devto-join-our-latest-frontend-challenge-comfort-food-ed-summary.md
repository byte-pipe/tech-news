# Join our latest Frontend Challenge: Comfort Food Edition 🍲

## Overview
- The challenge runs from July 29 to August 16.
- Build something inspired by the food that makes you feel at home.
- Open to CSS art, JavaScript‑heavy projects, or any mix of frontend skills.

## The Prompts

### CSS Art: Comfort Food
- Create a visual piece using primarily CSS (e.g., ramen bowl, pancakes, pie).
- Light JavaScript is allowed but the focus must remain on CSS.
- Use the provided CSS Art Submission Template.

### Perfect Landing: Comfort Food
- Design a polished, functional landing page with a food theme (real or imagined restaurant, recipe collection, food festival, etc.).
- Any browser‑compatible language/runtime may be used (JavaScript, TypeScript, Dart, WebAssembly, …).
- Use the Perfect Landing Submission Template.

## Judging Criteria & Prizes

### CSS Art
- Creativity  
- Effective use of CSS  
- Aesthetic outcome  

### Perfect Landing
- Accessibility  
- Usability and user experience  
- Creativity  
- Code quality  

### Prizes
- Each prompt winner receives a DEV++ Membership and an exclusive DEV Badge.  
- All participants with a valid submission earn a completion badge on their DEV profile.

## How to Participate
- Publish a post using the appropriate submission template and include the `#frontendchallenge` tag.  
- You may submit to one or both prompts; multiple submissions per prompt are allowed (separate posts).  
- Embed your project directly (e.g., Google Cloud Run, CodePen) to level up your post.  
- Review the judging criteria, rules, guidelines, and FAQ before submitting.

## Important Dates
- **July 29** – Challenge begins.  
- **August 16, 11:59 PM PDT** – Submission deadline.  
- **September 10** – Winners announced.
