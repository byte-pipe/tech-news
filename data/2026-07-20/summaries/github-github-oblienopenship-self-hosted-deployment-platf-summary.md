# GitHub - oblien/openship: Self-hosted deployment platform · GitHub

### Overview of Openships Self-Hosted Deployment Platform

**Key Points:**

* Openships is a self-hosted deployment platform that allows users to deploy and manage their applications.
* The platform provides built-in CI/CD capabilities and can be used to push changes directly onto the application.
* Users can choose from various stack configurations, including Node.js, Python, Go, Rust, PHP, Ruby, Java, and .NET.
* Openships supports full backend services, including databases, domains, SSL certificates, CDN, mail servers, backups, and real-time monitoring.

**Main Features:**

* Zero config files and zero pipelines
* Automatic deployment to production environments
* Integration with Docker and monorepos
* Built-in support for various operating systems
* Real-time monitoring and logging capabilities

**Frequently Asked Questions (FAQs):**

* Q: How do I get started with Openships?
A: To get started, you can use the built-in script `openship up` or the desktop app "Openship".
* Q: What operating system does Openships support?
A: Openships is available on various Linux distributions.
* Q: Can I deploy multiple applications using Openships?
A: Yes, Openships supports containerization of multiple applications.

**How it Works:**

1. Users create a new repository and link it to their project.
2. The platform builds the application, configures everything, and ships it directly onto production environments.
3. Push-to-deploy features allow users to automate changes to other repositories.
4. The built-in CI/CD capabilities ensure that changes are tested and deployed quickly.

**Benefits:**

* No configuration files or pipelines required
* Easy deployment of multiple applications from a single repository
* Built-in support for various operating systems and stack configurations
* Real-time monitoring and logging capabilities
