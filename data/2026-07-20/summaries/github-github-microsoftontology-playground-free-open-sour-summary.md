# GitHub - microsoft/Ontology-Playground: Free, open-source web app for learning about ontologies and Microsoft Fabric IQ. Explore a catalogue of pre-bu...

### Ontology Playground Overview

* A free, open-source web application for learning about ontologies and Microsoft Fabric IQ.
* Pre-built ontologies, visual editor, and interactive diagrams available.

### Key Features

* **Interactive Graph Exploration**: Cytoscape.js-powered graph that renders any ontology as an interactive node-and-edge diagram.
* **Ontology Catalogue**: Categorized library of official and community-contributed ontologies spanning six domains (Retail, E-Commerce, Healthcare, Finance, Manufacturing, Education).
* **Visual Ontology Designer**: Full-screen, split-pane editor for creating or editing existing ontologies.
* **RDF Import & Export**: Full round-trip support for RDF/XML (OWL classes, datatype properties, object properties with cardinalities).

* Zero backend dependencies and fully static site
