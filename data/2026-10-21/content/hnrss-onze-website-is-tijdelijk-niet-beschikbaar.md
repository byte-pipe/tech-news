# Onze website is tijdelijk niet beschikbaar

Vanwege de kwetsbaarheden in PHP hebben wij uit voorzorg onze website (NCSC.NL) tijdelijk offline
 gehaald. We werken hard aan een oplossing en doen er alles aan om de website zo snel mogelijk weer
 beschikbaar te maken. Voor actuele informatie over deze kwetsbaarheden verwijzen we je graag naar
 onzepagina op de NCSC
 Community.

## Patch om 16:00 uur verwacht

Het securityteam van PHP heeft een patch aangekondigd. De patch staat gepland om 16:00 Nederlandse
 tijd. Binnen een uur na het uitkomen van de patch verwachten we een advisory te publiceren opadvisories.ncsc.nl.

## NCSC-pagina op Github

Daarnaast heeft het NCSC eenpagina ingericht op Github. Hier vind je technische informatie over
 de kwetsbaarheden. Deze pagina wordt doorlopend geüpdate door het NCSC. Op dit moment wordt er gewerkt
 aan een inventarisatie van alle PHP-gerelateerde softwareproducten om inzichtelijk te maken welke
 producten kwetsbaar zijn.

## Overige informatie

In de tussentijd kun je ook voor nieuws, updates of vragen terecht op onzeLinkedIn-paginaen deNCSC
 Community. Organisaties die gebruik maken van onze CSIRT-dienstverlening kunnen terecht opMijnNCSC.

Onze excuses voor het ongemak en bedankt voor je begrip.
