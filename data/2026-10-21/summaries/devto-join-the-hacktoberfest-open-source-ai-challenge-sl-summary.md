# Hacktoberfest Open‑Source AI Challenge – Week 3 Summary

## Theme & Goal
- Theme: **Slow and Steady** – build with open‑weight or open‑source AI to reward laziness.  
- Goal: create tools that automate tedious tasks, help users relax, or run entirely offline.

## Participation Details
- **Dates:** October 19 – October 25, 2026 (submissions due 11:59 PM PDT).  
- Submit a DEV post using the provided template, describing the project, demo, and why open innovation matters.  
- New participants can start fresh; previous weeks do not affect eligibility.

## Example Project Ideas
- Local agent that reads group chats overnight and provides a two‑line morning summary.  
- Offline wind‑down companion that generates calming bedtime stories or ambient soundscapes.  
- Fridge‑photo‑to‑grocery‑list tool to avoid standing with the door open.  
- Automated file/inbox tidier that sorts, renames, and archives clutter.

## Prize Structure
- **Overall winner (1):** $250 USD, DEV++ membership, exclusive DEV badge.  
- **Featured category winners (6):** $200 USD each + exclusive badge.  
- **Partner category winners (14):** $100 USD each + exclusive badge.  
- All valid submissions receive a completion badge.

## Partner & Category Options
- 20 partner categories (e.g., Render, TabPFN, Tinker, Arduino, DigitalOcean, Gemma, Auth0, Browserbase, ElevenLabs, GitHub Copilot, MongoDB Atlas, etc.).  
- Projects may enter any category they genuinely use; a single project can compete in multiple categories but can win only once per challenge.  
- Partner category pools are smaller, increasing odds of winning.

## Judging Criteria
1. **Writing Quality** (heavily weighted): clarity, engagement, explanation of what was built, target audience, and open‑innovation impact.  
2. **Relevance to Prompt & Theme:** core use of open‑source AI/open‑weight models that saves effort or promotes relaxation.  
3. **Creativity:** originality or fresh take on a problem.  
4. **Technical Execution:** functionality and solid implementation.  
5. **Use of Partner Technology** (optional): meaningful integration of the selected partner’s tech.
