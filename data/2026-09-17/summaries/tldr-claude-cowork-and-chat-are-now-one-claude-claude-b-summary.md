# Claude Cowork and chat are now one Claude

## Overview
- Claude Cowork and chat are merged into a single Claude experience.  
- Rollout starts with Pro and Max plans; other plans will follow.  
- New integrated tools: Claude Docs, Claude Slides, and Claude Design (now usable inside conversations).  

## Key Features
- **Unified workflow** – ask Claude to create documents, presentations, or designs from the same conversation.  
- **Context‑aware** – Claude determines the required task type and applies existing skills, connectors, and data.  
- **Beta availability** – Docs, Slides, and Design are in beta on paid plans; Enterprise admins decide when to enable them.  
- **Flexible check‑ins** – default is to ask before acting; users can switch to autonomous mode with occasional confirmations.  
- **External data integration** – Claude can pull from sources (e.g., legal research databases), process, and store results for review.  

## Example Use Case
- User asks Claude for last week’s pipeline changes and requests a report plus five leadership slides.  
- Claude asks clarifying questions, generates a doc with notes and matching slides, and makes them available on the user’s phone.  
- User edits a line, comments on a slide, schedules the task for every Monday, and Claude starts the next report automatically.  

## Getting Started
- Chat‑only users continue as before; simply hand over larger tasks when needed.  
- Existing Cowork users keep all chats, projects, artifacts, connectors, and skills; they pick up where they left off.  
- No manual activation required for Pro/Max users; Team, Free, and Enterprise plans will receive the feature soon, with Enterprise admins receiving at least 30‑day notice.
