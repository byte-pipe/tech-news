# Quickstart install

If you want to run your own instance of Ghost, in most cases the best way is to use ourCLI tool

npm install ghost-cli -g

 

Then, if installing locally add thelocalflag to get up and running in under a minute -Local install docs

ghost install local

 

or on a server run the full install, including automatic SSL setup using LetsEncrypt -Production install docs

ghost install

 

Check out ourofficial documentationfor more information about ourrecommended hosting stack& properlyupgrading Ghost, plus everything you need to develop your own Ghostthemesor work withour API.
