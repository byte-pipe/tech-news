**WeChat-Article Exporter: A Web-Based Article Downloader**

This is a web-based tool for downloading articles from WeChat public accounts, allowing users to easily access and manage their article download history with various file formats.

* **Key Features**:
	+ Supports download of HTML, JSON, Excel, TXT, and MD format files.
	+ Provides a clean interface for searching and filtering articles by author, title, publication date, etc.
	+ Includes support for downloading comments, reply comments, reading quantity, and transfer quantity.
	+ Offers Docker deployment and Cloudflare deployment options.
* **Features and Functionality**:
	+ Supports crawling of WeChat public accounts to extract article content.
	+ Provides an API endpoint for interacting with the tool.
	+ Excludes scraping of account credentials to prevent unauthorized access.
	+ Includes a "Thank you" section for developers and supporters.
