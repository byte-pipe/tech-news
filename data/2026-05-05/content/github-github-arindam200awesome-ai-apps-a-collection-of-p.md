## Getting Started

### Prerequisites

* Python 3.10+(Python 3.11+ recommended for newer projects)
* Gitfor cloning the repository
* Package Manager:piporuv(recommended for faster installs)
* API Keys: Most projects require API keys (see individual project READMEs)

### Quick Start

1. Clone the repositorygit clone https://github.com/Arindam200/awesome-ai-apps.gitcdawesome-ai-apps
2. Choose a projectand navigate to its directorycdstarter_ai_agents/agno_starter#Example: Start with Agno starter
3. Set up environment variablescp .env.example .env#Copy example environment file#Edit .env with your API keys
4. Install dependencies#Using pippip install -r requirements.txt#OR using uv (recommended - faster)uv sync#oruv pip install -e.
5. Run the projectpython main.py#or for Streamlit appsstreamlit run app.py
