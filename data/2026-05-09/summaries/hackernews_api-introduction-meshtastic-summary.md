# Introduction | Meshtastic

## What is Meshtastic
- Community‑driven, open‑source project that turns inexpensive LoRa radios into a long‑range, off‑grid communication platform.
- Enables mesh communication without relying on existing or reliable infrastructure.
- Devices can connect via LoRa, Bluetooth, WiFi, or USB and be managed with the `meshtastic-cli`.

## Key Features
- Long‑range capability (recorded 331 km distance).
- No phone required for mesh messaging; works directly between radios.
- Decentralized network – no dedicated router needed.
- Encrypted communication for privacy.
- Low power consumption, providing excellent battery life.
- Text messaging between mesh members.
- Optional GPS‑based location services.
- Additional functionalities available through the open‑source ecosystem.

## How It Works
- Uses LoRa, a license‑free long‑range radio protocol, to broadcast and rebroadcast messages, forming a self‑healing mesh.
- Each radio can relay messages, ensuring delivery even to the most distant node.
- A single phone can pair with a radio, allowing personal messages to be sent directly to that device (one user per device at a time).
- Technical details are available in the project’s “Technical Overview” section.
