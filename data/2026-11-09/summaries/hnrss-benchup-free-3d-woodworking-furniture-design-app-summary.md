# BenchUp — Free 3D Woodworking & Furniture Design App

## Overview
- Free, open‑source 3D modeling tool for woodworking and furniture design.  
- Runs on Windows, macOS, Linux, or directly in a desktop browser.  
- No account required; works with mouse and keyboard.

## Core Features
- **Modeling tools**: draw lines, rectangles, circles, freehand outlines; push/pull faces; move, scale, offset, paint.  
- **Precision**: snap to geometry/axes, type exact lengths, add dimensions, tape measure.  
- **Organization**: groups, reusable components, tags.  
- **File handling**: autosave locally, download portable `.ketchup` projects, import SketchUp (`.skp`), export OBJ (`.obj`).  

## Typical Workflow for Woodworkers
1. **Create pieces** – sketch board outlines, give them thickness with Push/Pull.  
2. **Verify fit** – enter exact measurements, use snapping and dimension tools, orbit to review proportions.  
3. **Organize project** – group parts, tag components, save as portable project or exchange via SketchUp/OBJ.  

## Getting Started in Three Steps
1. **Draw a rectangle** – click opposite corners to create a face.  
2. **Add depth** – select Push/Pull, drag the face, click to confirm.  
3. **View model** – use Orbit to rotate, scroll to zoom, press **F** to fit view.  

## System Requirements & Data Storage
- Desktop browser with hardware acceleration and WebGPU or WebGL2 support; mouse and keyboard recommended.  
- Native apps available for Windows, macOS, Linux.  
- Models autosave in the browser; use **File → Save** to download `.ketchup` files. Clearing browser data removes autosaved work. No cloud storage or user accounts.

## Compatibility & Export Options
- Import SketchUp (`.skp`) files locally (textures and scenes not fully supported).  
- Export to Wavefront OBJ (`.obj`) – geometry only, without materials.
