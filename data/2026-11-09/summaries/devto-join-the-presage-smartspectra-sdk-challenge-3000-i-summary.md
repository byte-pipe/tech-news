# Join the Presage SmartSpectra SDK Challenge: $3,000 in Prizes Across 10 Winners! - DEV Community

# Summary of the Presage SmartSpectra SDK Challenge

## Challenge Overview
- Runs from **Nov 4** to **Nov 22**.
- Build an app using the Presage SmartSpectra SDK that reacts to real‑time human signals captured via camera (e.g., pulse, breathing rate, HRV, expressions).
- Total prize pool: **$3,000** across ten winners.

## Prompt
- **Best Overall Human‑Sensing Experience**: Create a functional experience that meaningfully uses live camera‑based signals.

## Prize Categories
- Participants may enter one or both of the following categories in addition to the overall prize:
  - **Most Creative or Delightful Use** – most original or playful application.
  - **Best Thoughtful Real‑World Use** – clear real‑world need, strong usability, consent, and responsible data handling.
- A single submission can win only once, but it may be eligible for the overall prize and either category.

## Submission Requirements 📌
- One entry per participant (no teams); participants must be 18 +.
- Must integrate the SmartSpectra SDK and use at least one live signal.
- Required deliverables:
  - DEV post using the provided template (include `#presagechallenge` tag).
  - Public code repository with clear SDK integration.
  - Setup instructions.
  - Demo video (public hosting optional).
  - Consent and data‑handling statement (storage, sharing, retention, deletion, telemetry, optional AI services).
- No medical diagnosis/treatment claims, covert monitoring, or non‑consensual use.

## Judging Criteria
- Effective use of the underlying technology.
- Usability and overall user experience.
- Originality and creativity.

## Prizes 🏆
- **Overall Winners (4)**: $300 cash, DEV++ Membership, exclusive DEV badge.
- **Most Creative or Delightful Use (3)**: $300 cash, DEV++ Membership, exclusive DEV badge.
- **Best Thoughtful Real‑World Use (3)**: $300 cash, DEV++ Membership, exclusive DEV badge.
- All valid submissions receive a completion badge on DEV.

## How to Participate
1. Publish a DEV post with the submission template and required tag.
2. Provide testing credentials if the app requires login.
3. (Optional) Attach an agent session transcript showing development steps.
4. Review judging criteria, rules, and FAQ before submitting.
