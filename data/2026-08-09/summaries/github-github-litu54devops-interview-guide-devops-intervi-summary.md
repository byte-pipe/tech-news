# DevOps‑Interview‑Guide Repository Overview

## Purpose
- Collects real interview questions from DevOps, SRE, and Cloud engineering interviews conducted in 2025‑2026.  
- Provides unedited, candidate‑submitted questions without paraphrasing or “top‑50” filler lists.

## Content Highlights
- **151 interview write‑ups** covering a wide range of topics: Kubernetes, Docker, Terraform, AWS/Azure/GCP, CI/CD (Jenkins, GitHub Actions, Azure DevOps), Ansible, Linux, scripting, and SRE fundamentals (SLI/SLO/SLA, observability, incident response).  
- **85 companies** represented, plus an `Others/` folder for anonymous submissions.  
- Multiple files per company when different candidates or interview rounds are present, preserving distinct question sets and interviewer styles.

## Organization Structure
- Each company has its own directory:  
  - `DevOps_Engineer.md` (default file when role isn’t specified)  
  - `DevOps_Engineer_2.md`, `SRE_principal.md`, etc., for additional interviews or specific roles.  
- Files are kept separate rather than merged to retain original context.  
- Anonymous interviews are stored under `Others/`.

## How to Use
- Search for a specific company name or browse folders to review questions across various organization sizes (product firms, service firms like TCS/Infosys/Wipro, fintech, etc.).  
- For broad preparation, skim multiple folders to understand the range of possible questions.

## Contributing Guidelines
- Add a new file in the appropriate company folder (create the folder if needed).  
- Use one‑file‑per‑interview format and include role and years of experience at the top when possible.  
- Place unnamed company submissions in `Others/`.
