## Installation

To install the new Windows Terminal, follow these steps:

1. Download the latest release from [GitHub](https://github.com/microsoft/terminal/releases).
2. Install on your target machine.
3. Launch Conhost.exe from the installation folder or via the `conhost.exe` command.
