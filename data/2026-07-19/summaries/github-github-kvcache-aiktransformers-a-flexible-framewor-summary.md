### Overview

KTransformers is a research project that provides a flexible framework for experiencing heterogeneous language model inference and fine-tuning. The project now offers two user-facing capabilities from the kt-kernel source tree, enabling users to explore cutting-edge language models on CPU-GPU heterogeneous computing.
