## # Apple Releases Safari Technology Preview 247 With MCP Server for AI Agent Integration

Apple today released a new update to its Safari Technology Preview, with version **247**. This latest update includes fixes and performance improvements, as well as the addition of a new feature: a **Model Context Protocol (MCP) server** that allows an **AI agent** to interact with web pages in a more realistic way.

### Key Points:

* New Safari Technology Preview 247 adds MCP server for AI agents
* Improements in debugging and web development, especially for accessibility and CSS updates
* Adds fixes for various system components, including fonts, forms, HTML, JavaScript, MathML, media, model elements, networkinbg, rendering, SVG, scrolling, security, spatial web, text, web API, webdriver, and WebGL

### Additional Details:

* Anyone can download the update through Software Update mechanism in System Preferences or System Settings
* Complete release notes are available on Safari Technology Preview website
* MCP server is compatible with any MCP-compatible client and accessible on Apples site
