### Main Features of Unity-MCP

Unity-MCP is a bridge between AI assistants and Unity Editor. It provides various tools and functionality to manage assets, control scenes, edit scripts, run tests, and automate game development workflows.

### Key Features and Functionality

* Supports multiple Unity instances
* Integration with local LLMs (Language Model Library)
* Controls the Unity Editor in natural language from any MCP client
* 47 focused MCP tool entrypoints for easy access to AI assistant functionality
* Fast and reliable deployment, with tools for testing and profiling

### Quickstart Guide

To get started, install Unity 2021.3 LTS using `Package Manager` or `uv Add com.coplaydev.unity-mcp`. Configure MCP for Unity in the `Window` > `MCP for Unity` settings. Prompts user input and displays the resulting cube scene.
