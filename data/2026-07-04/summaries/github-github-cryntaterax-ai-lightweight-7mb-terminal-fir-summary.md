**Terax: A Lightweight Terminal-first AI-native Dev Workspace**
====================================================================================

### Key Features

* **Terminal**: xterm.js with WebGL rendering, multi-tab support, and GPU-accelerated block-based terminal.
* **Code Editor**: CodeMirror 6 with a built-in theme editor and support for various programming languages.
* **Version Control**: Git history pane and source control panel with real commit graph (via lane rendering).
* **Agentic AI Workflows**: Interactive agentic AI side-panel for seamless integration.
