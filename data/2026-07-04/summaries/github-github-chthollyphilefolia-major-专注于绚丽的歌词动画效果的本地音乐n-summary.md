# GitHub - chthollyphile/folia-major: 专注于绚丽的歌词动画效果的本地音乐/navidrome/第三方网易云播放器 · GitHub

**GitHub - chthollyphile/folia-major:专注于绚丽的歌词动画效果的本地音乐 Navidrome/第三方网易云播放器**

### 项目简介
Folia是一个全屏沉浸式歌词播放器，支持NetEase、Navidrome和本地音乐库，通过智能歌词匹配生成AI主题和全屏歌词动画。

#### 主题预览
浮名、流光、心象、云阶、群唱、倾诉五种主题都可以选择，根据用户的喜好选择不同的歌词动画效果。

### 核心能力

* 模块管理
*在线搜索与播放
*本地音乐支持
*智能.song匹配
*LRC功能识别（自动Loading和增强型逐字歌词）

#### Now Playing接入
支持通过本机NowPlaying服务接入外部播放器。

### AI主题生成

基于song情绪分析和歌词内容匹配，生成沉浸式背景、视觉参数和全屏歌词动画。

#### 多端体验

同时提供Web版和桌面端打包分发能力，易于使用不同操作系统。

* 部署指南可自行部署到Vercel Web版本。
