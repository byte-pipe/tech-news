**Project Overview**

* Universal-Debloater-Alliance (UAD-ng) fork: removes unnecessary system apps from non-rooted Android devices
* Goal: improve device's privacy, security, and battery life by reducing obtrusive app execution

**Key Features**

* Cross-platform GUI developed in Rust using ADB
* Removes system apps to declutter device
* Debloates Android files for smoother performance

**How It Works**

* Uses adbd (Android Debug Bridge) for permission authentication
* Applies necessary changes as per requirements and notification settings
* Utilizes GitHub for package list updates and data transmission

**Documentation and Support**

* Extensive documentation available on Wiki and GitHub repository
* Offers Discord support, Matrix bridge, and suggestions for integrating with other projects and integrations

**Community Integration**

	+ AppManager (Android app manager)
