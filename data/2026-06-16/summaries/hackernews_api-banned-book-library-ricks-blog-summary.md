**Banned Book Library**

* **Overview**: Project Banned Book Library aims to create a digital repository of banned books by installing hackable smart light bulbs as makeshift web servers.
* **Key Points:**
  - Idea originated from reading Ben Brown's short story "Library", which featured characters hosting creative works online.
  - Hardware used is Tasmota, an open-source firmware that allows local control over connected devices, useful in projects like Banned Book Library.
  - Device choice is made due to cloud service issues and the need to preserve users' content locally.
* **Hardware**: Selected device is a Wi-Fi smart light bulb with built-in ESP32 chip.
* **Software**: Project uses Tasmota firmware for local control and manipulation of the devices.
