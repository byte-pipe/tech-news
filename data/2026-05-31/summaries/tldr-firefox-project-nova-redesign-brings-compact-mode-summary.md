# Firefox Project Nova redesign brings compact mode and new look

# Summary of Firefox Project Nova Redesign

## Key Visual Changes
- Softer, rounded tabs with a subtle gradient that emphasizes the active tab.  
- Consistent curves and spacing across panels, menus, and browser controls.  
- Redesigned icons for better balance in both light and dark themes.  
- New fire‑inspired colour palette featuring deep smoky purples and warm tones; active tab includes a glow effect.  

## New Functional Features
- **Compact mode** reintroduced to condense controls and save vertical screen space for power users.  
- Privacy tools made more visible: built‑in VPN (free 50 GB/month) receives prominent placement.  
- Settings rewritten in clearer language with easier controls for Enhanced Tracking Protection and a toggle to disable AI features entirely.  

## Performance Improvements
- Mozilla reports a 9 % increase in load times for key page content over the past year, aided by tracker blocking and prioritized loading of essential elements.  

## Cross‑Platform Consistency
- Shared colours, icons, and design tokens extend the new look to mobile Firefox, creating a unified experience across desktop and phone.  
- Introduction of new themes, wallpapers, and future customization options for interface elements such as tabs.  

## Underlying Design System
- Nova is built on a reusable token‑based design system, ensuring future features integrate with a cohesive visual language.  

## Market Context
- Firefox holds about 2.3 % of the global browser market, down from double‑digit shares a decade ago.  
- Competing browsers (Chrome, Safari) are emphasizing AI and platform integration; Firefox positions itself as user‑focused with optional AI features and a kill switch.  

## Release Plan
- Project Nova is currently available for testing in Firefox Nightly builds.  
- Full public rollout is expected later this year, with feedback collected via Mozilla’s Connect forum.
