# Chrome Again Exempts Google from User Site Data Settings

## Background

* 6 years ago, a blog post revealed a Chrome bug that exempted Google-owned sites from deleting user site data settings.
* Initially, the bug was reported on Hacker News, The Register, The Verge, and Gizmodo.
* The issue resurfaced 6 years later due to further investigation by the author, leading to Google fixing the bug.

## New Bug

* The author has re-created the same issue on two Macs with Chrome version 152.0.7977.83.
* They discovered that this new bug is related to the on-device site data settings, which delete data when a new window closes.
* Site data is allowed on-device settings, but not in Chrome settings or all page settings.

## Findings

* Google sites data are not deleted if the site is used as a Google site with signed-in credentials.
* Site data persistence includes Cookies, Local Storage, and Session Storage.
* The issue seems to be related to Google's default settings and QA processes.

## Conclusions

* Google has no reason for this bug to last, indicating incompetence in their QA processes.
* The author wishes Google would improve their QA processes to prevent such issues.
* The author expresses skepticism towards conspiracy theories and encourages Google to improve its features and processes.
