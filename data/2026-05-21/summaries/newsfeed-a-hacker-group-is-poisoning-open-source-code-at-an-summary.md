# A Hacker Group Is Poisoning Open Source Code at an Unprecedented Scale | WIRED

**GitHub Breach: Softwaresupply Chain Attack on Unprecedented Scale**

A recent software supply chain attack has compromised over 4,000 open source code repositories owned by Microsoft's GitHub platform. The hack is attributed to the notorious group "TeamPCP" that has carried out 20 "waves" of such attacks in just a few months.

**Key Points:**

* Hackers exploited a malicious extension for VSCode, a popular code editor, installed on a GitHub developer's computer.
* The extension contains malicious code shared with TeamPCP through the BreachForums forum and marketplace.
* At least 3,800 compromised repositories were discovered by GitHub, all containing its own code.
* The breach is part of a longer-running series of software supply chain attacks, affecting over 500 pieces of software.
* Company affected include AI firm Anthropic and data contracting firm Mercor.

**What This Means:**

* It is the latest incident in GitHub's growing list of victims, making it a significant threat to company networks worldwide.
* The attack showcases TeamPCP's ability to exploit vulnerabilities across various software platforms.
* As more companies come into contact with these compromised repositories, trust in an entire software ecosystem may be eroded.

**Why This Matters:**

* This breach highlights the importance of robust security measures when interacting with open source tools and code editors.
* It emphasizes the need for software developers to regularly update and secure their dependencies to prevent such attacks.
* The compromised code can be used as a starting point by attackers, leading to further exploitation of vulnerabilities.
