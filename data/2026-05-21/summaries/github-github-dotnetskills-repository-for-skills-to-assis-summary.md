**GitHub - dotnet/skills: Repository for Skills to Assist AI Coding Agents with .NET and C#**

This repository contains a curated set of core skills and custom agents for coding agents working with .NET.

### Key Features:

* **Agent Skills**: A collection of skills for handling common .Net coding tasks
* **Plugins**: Various plugins for .Net data access, performance investigations, debugging, and incident analysis management
* **MSBuild and NuGet**: Comprehensive MSBuild skills for failure diagnosis, optimization, and modernization, combined with NuGet and package management

### What's Included:

1. **Plugin Collection**:
	* dotnet: Core .NET skills
	* dotnet-data: .Net data access and Entity Framework related tasks
	* dotnet-diag: Performance investigations, debugging, and incident analysis
	* ...and more plugins for specific use cases
2. **MSBuild and NuGet**: All skills include comprehensive MSBuild skills for build diagnosis and optimization, as well as NuGet management for dependency management and package modernization
