# GitHub confirms breach of 3,800 internal repositories via malicious VS Code extension

By Sergiu Gatlan

### Key Points

- GitHub has confirmed that 3,800 internal repositories were compromised after an employee installed a malicious VS Code extension.
- The company removed the malware from the market place, isolated the device, and responded to the incident immediately.
- There is no evidence of customer data being compromised outside affected repositories.
- A cybersecurity group claims access to GitHub’s code and ~4,000 private code repositories.
- A previous hacker group linked to supply chain attacks claimed theft of sensitive data.

### Summary

GitHub has confirmed a breach of 3,800 internal repositories via a malicious VS Code extension installed by one of its employees. The company removed the malware from the market place, isolated the device, and launched an investigation into the incident. A security researcher claims that GitHub’s code was compromised but there is no evidence of data being extracted or stolen externally. This not only underscores the vulnerabilities in MS-Software development tools such as VSCODE but reveals another level of breach risks due to internal corporate supply chain.

### Additional Insights

*   The existence of malicious extensions with millions of installers indicates a high demand for these tools and suggests attackers are actively seeking vulnerable products.
*   The recent security incident involving an AI-based coding assistant highlights the growing threats in the world of cloud-based services.
*   External data loss or compromise might not be entirely isolated, as the potential impact on corporate interests can be substantial.
