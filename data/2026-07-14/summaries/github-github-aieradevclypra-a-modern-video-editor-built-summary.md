# Clypra - A Modern Video Editor for Tauri, React, and Rust

## Overview

Clypra is a professional-grade video editor built with Tauri v2, React 19, and Rust. It offers hardware-accelerated processing on desktop and mobile platforms, complete with optional AI-powered features.

## Key Features

* **Hardware Acceleration**: Native GPU decode via FFmpeg (VideoToolbox/D3D11VA/VAAPI) for optimized performance.
* **Cross-Platform Support**: Available on macOS (Apple Silicon & Intel), Windows, Linux, iOS (via Capacitor), and Android (via Capacitor).
* **Multi-Purpose Editing**: Import multiple format media files (video and audio), trim frames accurately, and perform multi-track timeline editing with precision timeline control.
* **AI-Driven Tools**: Enable natural language editing, auto-captions, smart reframing, and more using optional Pro features.

## Supported Platforms

### Desktop
* macOS (Apple Silicon & Intel)
* Windows
