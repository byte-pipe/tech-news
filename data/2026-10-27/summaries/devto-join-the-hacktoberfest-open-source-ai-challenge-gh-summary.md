# Join the Hacktoberfest Open‑Source AI Challenge: Week 4 – “Ghost in the Machine”

## Overview
- Week 4 runs from **October 26 – October 31** and ends on Halloween, coinciding with Día de los Muertos (Nov 1‑2).  
- Goal: build a project that uses **open‑weight models** or **open‑source AI** and reflects the spooky/Día de los Muertos theme.  
- One overall winner and one winner in each of **20 partner categories** will be selected.

## Theme & Project Ideas
- **Theme:** “Ghost in the Machine” – create something spooky or a tribute to the past using open‑source AI.  
- Example ideas:
  - Haunted terminal that comments on your commands.  
  - Virtual ofrenda builder for remembrances.  
  - Offline séance chatbot channeling a dead programming language.  
  - Local oral‑history recorder/transcriber.  
  - Ghost‑story generator using smart‑home sensor logs.  
  - Reviving an abandoned open‑source tool or internet relic.  

## Submission Requirements
- Publish a DEV post using the provided **Ghost in the Machine Submission Template**.  
- Explain:
  - What you built and how it fits the theme.  
  - Why open innovation matters for your project (offline capability, privacy, longevity, etc.).  
  - Demo or screenshots; optional DevRelay session embed.  

## Prize Categories
- **Overall winner:** $250 USD + DEV++ membership + exclusive badge.  
- **Featured categories** (6): $200 USD + badge each (e.g., Best Use of Render, TabPFN, Tinker, Arduino, DigitalOcean, Gemma).  
- **Partner categories** (14): $100 USD + badge each (e.g., Auth0 for AI Agents, Backboard, Browserbase, ElevenLabs, GitHub Copilot, MongoDB Atlas, etc.).  
- All valid submissions receive a completion badge.  

## Judging Criteria
1. **Writing Quality** – clarity, engagement, explanation of project and open‑innovation impact.  
2. **Relevance to Prompt & Theme** – core use of open‑source AI and thematic fit.  
3. **Creativity** – originality or fresh take.  
4. **Technical Execution** – functionality and build quality.  
5. **Use of Partner Technology** (optional) – meaningful integration for partner categories.  

## How to Participate
1. Write a DEV post following the submission template.  
2. Include project description, demo, and open‑innovation rationale.  
3. Review judging criteria, rules, and FAQ before submitting.
