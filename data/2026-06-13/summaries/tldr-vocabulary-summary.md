# Element Behavior and Layout

## How Elements Appear and Disappear

*   Introduction of elements
*   Fade in/out animation
*   Slide-in/slide-out animation
*   Scale-in/scale-out animation
*   Pop-in/Pop-out animation
*   Reveal animation
*   Keyframe animations define moments in an animation (0%, 50%, 100%).

## Coordinating Multiple Elements or Moments

*   Keyframes for defined points in an animation
*   Interpolation/Tween for generating in-between frames
*   Staggering multiple items with a small delay between each
*   Orchestration for deliberately timing animations
*   Delay for specifying the time before an annotation starts
*   Duration for setting how long an animation takes
*   Fill mode for determining whether an element keeps its first or last frame's styles
*   Stepped animation for dividing an animation into discrete steps

## Changing an Element’s Position, Size, or Angle

*   Translate move along the X or Y axis
*   Scale make an element bigger or smaller
*   Rotate spin around a point
*   Skew slant an element along the X or Y axis
*   3D tilt/flip rotate in 3D space to add depth
*   Perspective how strong the 3D effect looks — a lower value exaggerates depth

## Connecting One State, View, or Element to Another

*   Crossfade transition change one element's opacity while another grows/shrinks from its trigger spot.
*   Continuity transition maintain user orientation by visually connecting elements before and after.
*   Morph animate shape smoothly turns into another shape
*   Shared element animation travel and transform from one position into another
*   Layout animation adjust element size/position to the new spot
