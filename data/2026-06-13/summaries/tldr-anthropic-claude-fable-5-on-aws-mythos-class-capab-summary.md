# Anthropic Claude Fable 5 on AWS: Mythos-class capabilities with built-in safeguards now available | AWS News Blog

## Claude Fable 5 and Claude Mythos 5 now available on AWS

*   **Availability**: The latest update to Anthropic's Claude Fable 5 model is now available on Amazon Bedrock and Claude Platform on AWS.
*   **Key Capabilities**:
    *   Long-running, asynchronous execution
    *   Advanced vision capabilities with diagram recognition, chart interpretation, and table analysis
    *   Proactive self-verification for refining skills and ensuring high-quality outputs
*   **Safeguards**: The model features several built-in safeguards to prevent misuse in areas like cybersecurity, biology, chemistry, health, and more. In some cases, these limitations may be lifted if specific prompts are chosen (e.g., Opus 4.8 for security-related requests).
*   **Access and Usage**:
    *   On Amazon Bedrock, you can access the model programmatically using the Anthropic Messages API or through the AWS SDK.
    *   The Claude Platform on AWS offers a native experience with support for building applications within your existing environment.

This update allows users to harness the capabilities of Anthropic's Claude Fable 5 model in various contexts and is supported by a robust set of safeguards to ensure responsible use.
