# Presage SmartSpectra SDK Challenge – Summary

## Overview
- Runs from November 4 to November 22.  
- Build an experience with the Presage SmartSpectra SDK that reacts to real‑time human signals captured via camera (pulse, breathing rate, HRV, expressions).  
- Total prize pool: $3,000 across ten winners.

## Prompt
- **Best Overall Human‑Sensing Experience**: create a functional app that meaningfully uses live camera‑based signals through the SmartSpectra SDK.

## Prize Categories
- Participants may enter one or both optional categories; entries can also qualify for an overall win.  
- **Most Creative or Delightful Use** – reward for original, playful, or unexpected applications.  
- **Best Thoughtful Real‑World Use** – reward for clear real‑world need, strong usability, consent, and responsible data handling.  
- Each participant may submit only one entry; a submission can win only once.

## Submission Requirements 📌
- One entry per participant; no team submissions; participants must be 18 +.  
- Must integrate the SmartSpectra SDK and use at least one live Presage signal.  
- Required deliverables: DEV post, public code repository, setup instructions, demo video (public hosting optional).  
- Include a consent and data‑handling statement covering storage, sharing, retention, deletion, SDK telemetry, and any optional AI services.  
- Disallowed content: diagnosis/treatment claims, medical decision‑making, covert or non‑consensual monitoring.  
- Judges will verify SDK usage via the repository and demo video.

## Judging Criteria
- Use of underlying technology.  
- Usability and user experience.  
- Originality and creativity.

## Prizes 🏆
- **Overall Winners (4)**: $300 USD, DEV++ Membership, exclusive DEV badge.  
- **Most Creative or Delightful Use (3)**: $300 USD, DEV++ Membership, exclusive DEV badge.  
- **Best Thoughtful Real‑World Use (3)**: $300 USD, DEV++ Membership, exclusive DEV badge.  
- All valid submissions receive a completion badge on their DEV profile.

## How to Participate
- Publish a DEV post using the provided submission template and tag `#presagechallenge`.  
- Provide testing credentials or instructions if the app requires login.  
- Optional: embed an agent session transcript (Claude Code, Gemini CLI, Codex, GitHub Copilot CLI, Pi) and make it public before publishing.  
- Review judging criteria, rules, guidelines, and FAQ for eligibility and contest rules.

## Getting Started with SmartSpectra 🚀
- Learn about Presage and the SmartSpectra SDK.  
- Use the Desktop Starting Point (Node.js & Electron) for quick setup.  
- Register for an API key as a developer.  
- Read the Telemetry and Privacy guide for the consent section.  
- Access the SDK on GitHub and explore MLH resources for additional support.  
- Join the Presage Discord for questions; note that the challenge runs on a free trial with no extra credits.

## Important Dates
- **November 4** – Challenge begins.  
- **November 22, 11:59 PM PST** – Submission deadline.  
- **December 10** – Winners announced.
