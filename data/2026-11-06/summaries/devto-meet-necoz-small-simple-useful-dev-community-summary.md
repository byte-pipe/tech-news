# Meet Necoz! Small. Simple. Useful.

## Introduction
- I’m @nyaomaru, a frontend engineer who loves TypeScript and cats.  
- I launched an open‑source organization called **Necoz** to host the small tools I originally built for myself.

## Why Necoz?
- My personal utilities attracted users, bug reports, documentation fixes, and code contributions.  
- Open source feels more enjoyable when it’s collaborative, so I gave these projects a shared home.

## Philosophy: Small. Simple. Useful.
- Impact does not require massive projects; tiny utilities can solve real problems.  
- Even a single PR or a typo fix can help someone.

## Three Principles
### Open to Everyone
- First‑time contributors, seasoned engineers, or typo spotters are all welcome.  
- No expertise is required to participate.

### Build Something Useful
- Focus on small tools that address concrete needs.  
- One useful function can be enough; a project need not have countless features.

### Be a Good Cat
- Be kind, curious, and respectful.  
- Disagreements should stay respectful, and mistakes are part of learning.

## Projects
### is‑kit
- A zero‑dependency TypeScript toolkit for creating and composing reusable type guards.  
- Features: build/reuse guards, compose with `and`, `or`, `not`, `oneOf`, refine keys, validate shapes, parse/assert values without a heavy schema framework.

### changelog‑bot
- Generates polished changelogs from GitHub history, with optional AI‑enhanced summaries.  
- Provides a CLI and GitHub Action; can open a PR with updated changelog automatically.  
- Works with OpenAI or Anthropic, or falls back to heuristic summarization.
