# Scenario Agent Skills – Repository Overview

## Repository Structure
- Contains folders for agents, skills, documentation, tests, and configuration files.
- Key files: `README.md`, `INSTALL.md`, `AGENTS.md`, `CHANGELOG.md`, `LICENSE`.

## Purpose
- Provides **Agent Skills** that enable AI coding agents (Claude Code, Cursor, Codex, Copilot, etc.) to create production‑ready assets through the Scenario MCP server.
- Assets include images, video, audio, textures, skyboxes, 3D models, and custom‑trained models for games, entertainment, and other creative fields.
- Includes **Expert Tools** families that drive DCC software and game engines (ZBrush, Blender, Maya, Unreal, Unity, Godot, Roblox Studio) using distilled tutorials and official documentation.

### Expert Tools Families
- Install an entire family (e.g., Blender, Maya) via its README or the installer menu.
- Requires the corresponding DCC application on the local machine.

### Connecting to Scenario MCP
```bash
claude mcp add --transport http scenario https://mcp.scenario.com/mcp
```
- Alternatively add the MCP URL to any client and authenticate via OAuth or API key.

## Keeping Skills Updated
- Releases are generated by `release-please`; each PR tags a version, updates `CHANGELOG.md`, and publishes a GitHub release.
- To monitor changes: watch the repository’s releases.
- To update installed skills: `npx skills update` or re‑run the original add command.
- Pin a reviewed state by specifying the release tag and commit hash.

## Skill Categories

### Getting Started
- **scenario** – Connects to the Scenario MCP and runs the core generation loop (discover, schema, run, wait, display, download).

### Finding a Direction
- **scenario‑inspiration** – Generates references, concept options, and moodboards to guide subsequent asset creation.

### Image Generation & Editing
- **scenario‑image** – Text‑to‑image, model selection, sizing, masked inpainting, post‑processing.
- **scenario‑multi‑reference** – Combines multiple reference images, each defining a specific attribute (subject, style, palette, etc.).
- **scenario‑product‑shots** – Produces product photography from a base photo, including relighting and label fidelity checks.
- **scenario‑brand‑kit** – Creates visual identity assets (SVG logos, palettes, type specs) with gated variants.
- **scenario‑image‑editing** – Applies tool‑model edits such as LUT grades, effects, resizing, slicing, and layering.

*(Further skill groups continue for video, audio, 3D, workflows, moderation, analytics, and model training as listed in the install command.)*
