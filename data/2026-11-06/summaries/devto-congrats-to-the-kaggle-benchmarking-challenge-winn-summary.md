# Kaggle Benchmarking Challenge Winners

## Overview
- Partnered with Kaggle to create benchmarks that test whether models truly understand real‑world tasks, not just leaderboard positions.  
- Participants designed evaluations that start from known difficult problems, providing meaningful measurements of model performance.

## Highlighted Submissions
- JonathanSolvesProblems – Tested 19 frontier models on the Calgary time‑zone change; all gave the wrong answer despite Alberta stopping DST.  
- Nazar Boyko – Measured memory usage across PHP and Go versions; models quoted correct release notes but applied them to the wrong situation, often with high confidence.  
- Dhotiiiii – Asked ten LLMs for Blender 5.0 scripts and actually ran each script; only a subset produced code that executed correctly and noted version differences.  
- Kai Chen – Recreated 26 historic, costly software bugs; models flagged problems almost every time but frequently for the wrong reasons, including false positives like SQL injection.  
- Butnar Daniel – Tested 43 models on Romanian letters that resemble Turkish ones; about one‑third of the answers retained the incorrect letter when the input was misspelled.
