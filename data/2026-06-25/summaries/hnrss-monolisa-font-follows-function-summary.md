# MonoLisa – font follows function

## Overview
- MonoLisa is a monospaced typeface designed for developers and creatives.
- Aims to improve code legibility while providing a clean sans‑serif for design tasks.
- Available for testing before purchase.

## User testimonials
- Developers and instructors highlight its readability, distinct characters, and pleasant personality.
- Users report reduced eye strain, especially those with vision conditions.
- Many consider it their default font for terminals, IDEs, and design work, noting that switching back to older fonts feels like a downgrade.
- Adopted as the default font by platforms such as snappify.io.

## MonoLisa family
- Consists of **MonoLisa Code** (optimized for programming) and **MonoLisa Text** (optimized for long‑form prose).
- Both share the same design principles: distinctive letterforms, balanced spacing, and extensive language coverage.
- Presented as a pairing suited for the AI era—code and prose rendered with consistent clarity.

## Key features

### Distinction
- Glyphs are designed to be visually distinct, reducing ambiguity between similar characters (e.g., `I`, `l`, `1`; `d`, `b`; `C`, `G`).

### Italics & Script
- Includes a standard italic style.
- Offers a script variant for a handwritten appearance when italics are insufficient.

### Variable font
- Single variable font file with two axes:
  - **Weight**: from Thin to Black.
  - **Grade**: adjusts stroke thickness without altering glyph widths, useful for different surface colors or personal preference.
- Both axes apply uniformly to MonoLisa Code and MonoLisa Text, keeping prose and inline code in sync.

### Language support
- Supports over 200 languages and scripts, including Latin, Armenian, Cyrillic, Greek, Hebrew, and more.
- Consistent design quality across all supported alphabets.
