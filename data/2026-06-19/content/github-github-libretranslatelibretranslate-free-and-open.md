# LibreTranslate

Try it online!|API Docs|Community Forum|Bluesky

 
 
 
 

Free and Open Source Machine Translation API, entirely self-hosted. Unlike other APIs, it doesn't rely on proprietary software such as Google or Azure to perform translations. Instead, its translation engine is powered by the open sourceArgos Translatelibrary.
