#### OfficeCLI: The AI-Powered Office Suite

**Overview**
-----------

GitHub iOfficeAI has released OfficeCLI, a fully customizable and open-source Office suite designed specifically for artificial intelligence (AI) agents. This suite allows AI agents to read, edit, and automate Word, Excel, and PowerPoint files.

**Key Features**
----------------

* **Single Binary**: No Office installation required
* **Open-Source**: Easy to integrate into existing AI workflows
* **No Dependencies**: Works everywhere with minimal configuration
* **Html Rendering Engine**: Produces high-fidelity documents for AI agents

**How It Works**
----------------

1. **Installation**: paste the `SKILL.md` file into an AI agent's chat or download the binary from GitHub Releases using the CLI.
2. **GUI Option (for humans)**: Install OfficeCLI through a GUI app, AionUi, and let it integrate with your existing workflow.

**Technical Details**
----------------------

* **Codebase**: Open-source and single binary
* **Encoding**: Produces HTML or PNG renditions of documents

#### Getting Started

#### Option 1 (GUI) - Installation
Paste the `SKILL.md` file into an AI agent's chat, let OfficeCLI install automatically.

#### Option B (CLI) - Download Binary for Platform

Use the following command to download and run OfficeCLI:
```bash
officecli install
```
Copy the binary to your PATH and install all necessary dependencies.
