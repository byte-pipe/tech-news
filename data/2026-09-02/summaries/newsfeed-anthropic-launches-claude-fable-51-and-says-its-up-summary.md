# Anthropic launches Claude Fable 5.1 and says it’s up to 45 percent cheaper for agentic work  

## Key announcements  
- Anthropic introduced two new models: **Claude Fable 5.1** and **Mythos 5.1**.  
- Fable 5.1 is marketed as offering stronger performance than Fable 5 while costing about 25 % less on typical workloads and up to 45 % less on complex agentic tasks, thanks to cheaper pricing on cached data.  
- Mythos 5.1 launches exclusively within **Project Glasswing**.  
- Safeguards are refined: Fable 5.1’s safeguards are “more precise,” reducing unnecessary blocks on basic biology questions; Mythos 5.1 retains the same biology restrictions as its predecessor.  
- Anthropic announced “Enterprise Frontier Safeguards,” which store customer data on the client’s own cloud servers for complete privacy; rollout is planned for later this fall.  

## Early user impressions  
- **Dan Shipper (Every CEO)**: “It’s the strongest coding model we’ve used, but now it’s fast, token‑efficient, and crucially actually speaks like a normal person.”  
- **Aaron Levie (Box CEO)**: Box’s agent using Fable 5.1 detected subtleties and ambiguities that Fable 5 missed in the same test.  
- **Lisan al Gaib**: On benchmarks, Mythos 5.1 with low‑reasoning settings scores the same as its predecessor set to max reasoning.  

## Expanded use cases  
- Fable 5.1 is now allowed for identifying software vulnerabilities.  
- Certain cybersecurity tasks—penetration testing, exploit generation, binary‑based vulnerability scanning—will continue to be routed to Opus models.  

## Availability  
- **Claude Fable 5.1**: available on all Anthropic platforms.  
- **Mythos 5.1**: available only to participants in Project Glasswing.
