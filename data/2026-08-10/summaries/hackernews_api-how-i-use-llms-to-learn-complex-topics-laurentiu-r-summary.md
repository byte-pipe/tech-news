# How I use LLMs to learn complex topics · Laurentiu Raducu

## The flow
- In “plan mode” (using CC or OpenCode) I ask a model to create a foundational knowledge base for a chosen topic.  
- I request the model to review the accuracy of that knowledge base.  
- I then have the model generate a low‑poly, RollerCoaster‑Tycoon‑style animation that simulates the topic, adding UX features such as responsive layout and stop controls.  
- Finally I push the code to a new repository and enable GitHub Pages to host the interactive demo.

## The result
- The output is a visually appealing animation that is claimed to be 100 % accurate and free of hallucinations.  
- Compared with reading long articles or bulleted lists from search results, the interactive simulation makes the material stickier and easier to understand.  
- I applied this method to chip manufacturing and published the demo at **ChipTycoon**, where a cart travels from sand collection to finished chip delivery, illustrating each production step.

## How to improve it further
- Replace overly abstract low‑poly assets with realistic 3‑D objects generated via a picture‑to‑3‑D model tool, then map them into the simulation for higher fidelity.  
- Add knowledge‑check challenges and intuitive puzzles that ask users to recall previous steps, boosting retention.
