# If you love a website, back it up – The Future Is Now

## Why I’m writing this
- I lost a beloved fansite (teapuppies.com) that had been online unchanged since 2004; the domain now shows gambling ads.  
- As someone who works in web archiving, I should have saved it, but I didn’t.  
- I want to show that anyone can preserve webpages they care about instead of waiting for large organizations.

## What you need to know
- Personal web archiving is possible with standard formats like **WARC/WACZ**; you don’t need deep technical knowledge.  
- The tools I mention are mostly free (the company I work for makes them, but they’re not paid for you).  
- An entire archived site can be embedded in a blog post and downloaded for personal use.

## Tools for personal archiving

### Option 1 – ArchiveWeb.page browser extension
- Install the Chrome extension.  
- Open the first page you want to capture, click the extension icon → “Start Archiving”.  
- Interact with any dynamic elements to load their data.  
- Visit additional pages; the extension adds them to the same collection.  
- Click the icon again → “Stop Archiving”.  
- Use the dashboard to preview, load, or share the archived pages.

### Option 2 – archiveweb.page app
- Stand‑alone application with its own built‑in browser.  
- Works like the extension but without needing Chrome.  
- Opens directly to a menu for browsing your local archives.

### Option 3 – Browsertrix
- Web‑crawler tool for larger sites that are impractical to browse manually.  
- Provide a start URL; the crawler follows links and saves everything it can.  
- Can be limited to specific paths (e.g., only `/episodes/`).  
- Primarily a web app; offers a 7‑day free trial, then paid per use.  
- Open‑source, so you can self‑host if you prefer.

## Viewing your archived pages
- Load the WARC/WACZ file in ArchiveWeb.page or ReplayWeb.page to browse locally, just like a live site.  
- To share privately, send the archive file to others for loading in the same tools.  
- To share publicly, embed the ReplayWeb.page viewer on any website or blog; only a file upload and a bit of JavaScript are required.

## Keeping the data safe
- The archive is a single WACZ file, easy to copy and store.  
- Make multiple copies and distribute them to friends or collaborators to ensure redundancy.

## Call to action
- Identify a favorite site, post, or piece of information you don’t want to lose.  
- Use one of the tools above to back it up today.  
- Share the archive with others so the preservation effort is collective.
