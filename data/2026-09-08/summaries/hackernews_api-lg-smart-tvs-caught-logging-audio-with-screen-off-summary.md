# LG smart TVs caught logging audio with screen off and snooping on local devices

## Key Findings
- LG OLED models (including G5) continuously scan home networks, mapping secondary devices such as phones and smartwatches, and collect Wi‑Fi network names, signal strengths, and location data.  
- Collected data is sent to LG Ad Solutions, which claims access to 363 million addressable devices in the US, far exceeding the 216 million TVs sold globally.  
- The TVs run Automated Content Recognition (ACR), creating digital fingerprints of on‑screen audio/video to log viewing habits across inputs.  
- Bench tests showed the built‑in microphone can capture clear audio while the screen appears off (standby mode). The TV stores recordings locally and uploads them when network connectivity returns.  
- Researchers identified remote code execution vulnerabilities in webOS that are currently undergoing responsible disclosure.  

## Implications
- Broad network listeners and data sweeps enable extensive user profiling without explicit consent.  
- Audio recording in standby raises privacy concerns, especially since recordings are retained and later transmitted.  
- Unpatched vulnerabilities could allow attackers to gain control of the TV and the connected network.  

## Recommendations
- Disconnect LG smart TVs from the internet when not needed.  
- Use external streaming devices for media consumption to avoid built‑in data collection features.
