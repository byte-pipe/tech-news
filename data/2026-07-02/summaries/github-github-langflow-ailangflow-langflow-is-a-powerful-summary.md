# GitHub - langflow-ai/langflow: Langflow is a powerful tool for building and deploying AI-powered agents and workflows. · GitHub

### **Overview of Langflow**

Langflow is a powerful tool for building and deploying AI-powered agents and workflows. It provides developers with both a visual authoring experience and built-in API and MCP servers that turn every workflow into a tool.

### **Key Features - Main Functional Highlights**

*   **Visual Builder Interface**: Quickly get started and iterate with the visual interface.
*   **Customizable Source Code**: Access to source code options for customization.
*   **Interactive Playground**: Immediately test and refine flows with step-by-step control.
*   **Multi-Agent Orchestration**: Conversation management and retrieval features.
*   **API Deployment**: Deploy as an API or export as JSON for Python apps, while being exported from MCP servers.

### **About Langflow Desktop**

Langflow Desktop is the easiest way to get started with Langflow. It includes all dependencies, simplifying setup and avoiding environment management. Available on Windows and macOS, providing a user-friendly experience.
