### How to Translate a Program 📝

I. Submit a Pull Request

* Fork the repositoryhere.
* Download theEnglish base file (Localize.xaml)orbrowse and copy fromexisting translationsin other languages.
* Translate the file and save it in a folder named after yourlanguage code(e.g.,kofor Korean,frfor French).For regional variants: language-region (e.g.,pt-brfor Brazilian Portuguese,zh-cnfor Simplified Chinese).
* Place the folder in:

📂 .Source
└── 📁 GTweak
 └── 📁 Languages
 ├── 📁 en
 ├── 📁 ru
 └── 📁 [your-language-code]
 

* Add your language’s name (as written in your native language) toLanguageCatalog.⚠️Make sure to follow theNOTEinside the file.
* Submit aPull Requestwith your changes.

II. Request via Issue

* If you’re unfamiliar with Git, open aFeature Request issue.Specify your targetlanguage code.Provide the name of your language written in your native language according to theNOTE.Attach your translatedLocalize.xamlfile.
* Specify your targetlanguage code.
* Provide the name of your language written in your native language according to theNOTE.
* Attach your translatedLocalize.xamlfile.

Note

The current translation may be incomplete, as new features might have been added that haven't been translated yet. In such cases, those parts of the program will appear in English by default.
