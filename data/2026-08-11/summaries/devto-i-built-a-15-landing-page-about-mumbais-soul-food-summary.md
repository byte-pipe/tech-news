# Maharashtra's Vada Pav Landmark - ₹15 Street Food Project Completed

## Key Highlights:

- Developed a scroll-driven cinematic landing page showcasing Mumbai's Vada Pav, a popular street food.
- Built from scratch using HTML5 and CSS with minimal use of frameworks or libraries.
- Implemented interactive 5-step assembler with tab UI, image swap, progress bar to showcase recipe details.
- Integrated "Unwritten Rules" of eating vada pav in the Recipe section.
- Utilized TypeScript for server-side rendering (SSR) due to its ability to handle complex layout changes.
- Designed a dark and cinematic aesthetic with Tungsten bulb glow effects and saffron accents.

## Technical Details:

* Implemented navigation using requestAnimationFrame, easing interpolation between links and sections.
* Used IntersectionObserver for scroll-reveal functionality.
* Built-in accessibility features include semantic HTML5 elements, role-based tablisting, keyboard navigation, ARIA attributes, lang attribute with Marathi text, prefers-reduced-motion, and WCAG AA color contrast verification.

## Emotional Impact:

- The project aims to evoke the emotional connection people have with Mumbai's Vada Pav.
- By highlighting the transformative journey from counting coins for buses to earning in millions, the page conveys a sense of aspiration and happiness.
