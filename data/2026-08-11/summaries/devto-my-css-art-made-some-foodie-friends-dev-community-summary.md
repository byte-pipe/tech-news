# My CSS Art Made Some Foodie Friends 🍙🧋🥟🍲 - DEV Community

**CSS Art Submission for Comfort Food Edition**

### Introduction

A collection of 9 high-polygon 3D objects are grouped into a restaurant scene and a self-order kiosk to create a visually appealing and interactive experience.

* A **dark neon-lit restaurant with digital menu display**, featuring characters that bounce and blink on screens.
* The customer interface displays ordering information, including prices and payment details.

### Design Inspiration

The collection is inspired by comfort food dishes, which are often simple yet satisfying meals. The artwork aims to capture the essence of these dishes with bold colors and shapes.

### Technology Used

- Built using modern CSS skills
- Implemented using clip-path, border-radius, and gradients for animation.
- Utilizes vanilla JavaScript for simple interactions.

### Animation

A custom-made single-click event handler allows each character to display animated reactions when clicked. The character's animation includes bounce, blink, and sparkle effects.

* **Characters**: Each shape (e.g., **onigiri**, **boba tea**, etc.) is wrapped in a `.characterwrapper` with variations of the face, mouth, cheek, and eye parts. Infinite floating, bounce, blinking, squish, and sparkle-burst effects are applied.
* **Interactive Components**:
	+ The customer interface has an animated kiosk sequence that involves typing orders into a touchscreen display.
