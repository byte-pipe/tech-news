# Anthropic adds 28 security and compliance integrations for Claude

## Overview
- Anthropic released 28 new integrations that connect Claude Enterprise with security and compliance platforms.  
- The integrations use the Claude Compliance API to give IT and security teams programmatic, real‑time access to usage data and content.

## Claude Compliance API capabilities
- **Conversation content**: chats, uploaded files, and projects can be inspected for DLP and other security policies.  
- **Activity events**: user logins, admin actions, and configuration changes provide visibility into organizational usage.

## Benefits for enterprises
- Enables continuous monitoring and automated policy enforcement, replacing manual exports and periodic reviews.  
- Data flows into existing dashboards and alerting workflows of the connected security tools.

## Integration categories
- DLP, SASE, data security, SIEM, security operations, identity management, eDiscovery, AI security posture management, observability.

## New integration partners
- Cloudflare, Cribl, CrowdStrike, Cyera, Datadog, Forcepoint, Fortinet, Geordie AI, IBM Guardium, Microsoft Purview, Mimecast, Netskope, Okta, Palo Alto Networks, Proofpoint, Relativity, ReliaQuest, Rubrik, SailPoint, Smarsh, Snyk, Sumo Logic, Tenable, Theta Lake, Trellix, Varonis, Wiz, Zscaler.

## Quote from Anthropic
- “For organizations already using one of these security and compliance platforms, enabling coverage over your Claude usage is straightforward: connect and configure your Claude instance, and the data flows into the same dashboards and alerting workflows you use for everything else.”
