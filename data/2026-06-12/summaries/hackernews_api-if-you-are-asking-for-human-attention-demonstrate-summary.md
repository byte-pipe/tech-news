# If You are Asking for Human Attention, Demonstrate Human Effort | Tom Bedor's Blog

**Understanding the Growing Issue of Human-AI Input**

As AI-generated content becomes increasingly prevalent, a question arises on when to use human input versus automating tasks. On one hand, robots like language models can produce useful and innovative output. However, this can lead to fatigue as software engineers spend more time reading AI-generated text.

**Key Takeaways**

*   When working with a team, consider the context and intention behind using AI-generated content.
*   If providing human intervention is not worth its time, it may not be worth requesting in the first place.
*   Demonstrate human effort by labeling human-generated content and adding commentary to supplement.

**Best Practices for Working with Artificial Intelligence**

1.  **Use Human Input When Possible**: If human intervention can improve output or provide necessary perspective, consider using AI-generated content when feasible.
2.  **Label AI-Generated Content**: Clearly note that the content was generated by AI tools and include any subsequent comments or changes made by humans.
3.  **Human Feedback is Valuable**: Providing feedback on non-human-generated content can also be valuable in a collaborative effort.

**The Human Touch**

By incorporating human input wherever possible, we can demonstrate professionalism, consideration, and show appreciation for the value other professionals bring to our work.
