# MacOS 27 Beta Breaks Asahi Linux Boot Capability

## Summary

Asahi Linux has warned its users about a recent change in macOS 27 beta that makes it impossible to boot the partition, which was previously hidden due to data loss.

## Key Points

* macOS 27 beta introduces a new boot picker and Startup Disk handling system.
* The Asahi Linux partition is now visible and can be booted without losing data.
* Users are advised to wait for Apple's response before trying out the beta version.
* Those who try it out may need a secondary installation of an older macOS version.

## Information

- Asahi Linux filed a bug report with Apple about this change.
- The company is waiting to hear more from Apple and is warning users against using macOS 27 beta now.
