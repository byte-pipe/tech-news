# Join the Presage SmartSpectra SDK Challenge: $3,000 in Prizes Across 10 Winners! - DEV Community

# Presage SmartSpectra SDK Challenge Summary

## Overview
- Runs from November 4 to November 22, 2024.
- Build a real‑time human‑signal experience using the Presage SmartSpectra SDK (e.g., pulse, breathing rate, HRV, expressions).
- $3,000 total in cash prizes across ten winners.

## Prompt
- **Best Overall Human‑Sensing Experience**: create a functional app that meaningfully reacts to live camera‑captured signals.

## Prize Categories
- **Most Creative or Delightful Use** – original, playful, or unexpected applications.
- **Best Thoughtful Real‑World Use** – clear real‑world need, strong usability, consent, and responsible data handling.
- Entries can compete for an overall win and/or one or both categories, but each participant may submit only one entry and each entry can win only once.

## Submission Requirements 📌
- Individual participants only (18+); no team submissions.
- Integrate the SmartSpectra SDK and use at least one live signal.
- Provide a DEV post, public code repository, setup instructions, and a demo video (public hosting optional).
- Include a consent and data‑handling statement covering storage, sharing, retention, deletion, SDK telemetry, and any optional AI services.
- Disallowed: diagnostic/treatment claims, medical decision‑making, covert or non‑consensual monitoring.

## Judging Criteria
- Effective use of the underlying technology.
- Usability and overall user experience.
- Originality and creativity.

## Prizes 🏆
- **Overall Winners (4)**: $300 USD, DEV++ Membership, exclusive DEV badge.
- **Most Creative or Delightful Use (3)**: $300 USD, DEV++ Membership, exclusive DEV badge.
- **Best Thoughtful Real‑World Use (3)**: $300 USD, DEV++ Membership, exclusive DEV badge.
- All valid submissions receive a completion badge on DEV.

## How to Participate
- Publish a DEV post using the provided submission template and tag it `#presagechallenge`.
- Include testing credentials if the app requires login.
- (Optional) Attach an agent session transcript to show development workflow; make it public before publishing.
- Review judging criteria, rules, guidelines, and FAQ for eligibility details.

## Getting Started with SmartSpectra 🚀
- Learn about Presage and read the SmartSpectra Docs.
- Use the Desktop Starting Point (Node.js/Electron) to bootstrap.
- Register for an API key as a developer.
- Read the Telemetry and Privacy guide for consent handling.
- Access the SDK on GitHub.
- Additional resources: MLH guides and Presage Discord for support.
- Note: the challenge runs on Presage’s free trial; contact Discord if you hit credit limits.

## Important Dates
- **Nov 4** – Challenge begins.
- **Nov 22, 11:59 PM PST** – Submission deadline.
- **Dec 10** – Winners announced.
